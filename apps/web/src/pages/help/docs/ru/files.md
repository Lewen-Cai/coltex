# Файлы

## Дерево файлов

- Кнопки в его заголовке: новый файл, новая папка, загрузка и добавление связанного файла.
- Перетащите файл на папку, чтобы переместить его; дважды щёлкните имя, чтобы переименовать. Файлы, перетащенные с компьютера, загружаются в проект.
- Щёлкните файл или папку правой кнопкой, чтобы создать, загрузить, переименовать или удалить.
- Цветная точка рядом с файлом означает, что он открыт у кого-то другого.

Удалённые файлы можно вернуть из истории.

## Связанные файлы

Связанный файл берётся из другого места, и его в любой момент можно обновить из источника:

- **Из другого проекта**: любой файл другого проекта или его скомпилированный PDF (сначала выполняется сборка). Удобно для общих рисунков или общего `.bib`, а также чтобы использовать PDF одного проекта как рисунок в другом.
- **По URL**: загружается с публичного адреса (до 50 МБ). Адреса локальной или частной сети использовать нельзя.

> Связанные файлы отмечены в дереве значком ссылки; наведите указатель, чтобы увидеть, откуда они. Команда **Обновить связанный файл** в контекстном меню загружает файл заново и заменяет его. Чтобы добавить или обновить файл, нужен собственный доступ к исходному проекту.

## Git

Любой проект можно клонировать, а также выполнять в нём pull и push с помощью git:

1. Создайте токен для Git в разделе **Настройки → Службы синхронизации** (он показывается один раз — сохраните его). Токен с доступом **Только чтение** позволяет клонировать и выполнять pull, но не push.
2. Скопируйте адрес для клонирования в настройках проекта и выполните `git clone <address>`. Когда git спросит, укажите любое имя пользователя, а в качестве пароля — токен.
3. Сделайте коммит локально и выполните `git push`: изменения сразу попадут в проект, где их увидят соавторы.

Полезно знать:

- У каждого проекта одна ветка — `main`.
- Если кто-то изменил проект после вашего последнего pull, git отклонит push: сначала выполните `git pull`, затем push ещё раз.
- Перед применением push состояние проекта сохраняется как версия.
- Рецензенты и читатели не могут выполнять push.
- Чтобы не вводить токен каждый раз: `git config --global credential.helper store` (или `osxkeychain` на Mac).
