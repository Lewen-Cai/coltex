# Начало работы

ColTex — редактор LaTeX для совместной работы, работающий на вашем собственном сервере. Он очень похож на Overleaf: исходный код слева, PDF справа, и несколько человек могут одновременно редактировать один проект.

## Новые проекты

Нажмите **Новый проект** вверху слева, укажите название и выберите шаблон:

| Шаблон | Класс |
| --- | --- |
| Пустая статья | Стандартный `article`, самое простое начало |
| Препринт arXiv | `article`, одна колонка, авторы с аффилиациями (authblk), библиография natbib |
| Конференция IEEE / журнал IEEE | `IEEEtran` в режиме конференции / журнала |
| Конференция ACM / журнал ACM | `acmart` sigconf / acmsmall |
| Springer LNCS | `llncs`, для LNCS и других сборников трудов Springer |
| Журнал Elsevier | `elsarticle`, препринт в одну колонку |
| APS (REVTeX 4.2) | `revtex4-2`, для журналов Physical Review и AIP |

Кроме пустой статьи, каждый шаблон содержит аннотацию, ключевые слова, формулу, рисунок, таблицу и `references.bib` и собирается без изменений. Классы — официальные, входящие в TeX Live. Конференций, которые каждый год выпускают новые стилевые файлы (NeurIPS, ICML), в TeX Live нет: загрузите файлы нужного года в проект и опубликуйте его как шаблон.

Проекты, которые пользователи опубликовали как шаблоны (например, формат диссертации группы), перечислены в разделе «Общие на этом сервере».

Новые проекты компилируются в режиме **Автоматически**: движок выбирается при каждой сборке по документу; см. [Компиляция и PDF](#/help/compiling).

Чтобы перенести проект из Overleaf, выберите там **Download Source** и импортируйте zip здесь через **Импорт** (до 200 МБ). Главный документ определяется автоматически, а компилятор тоже будет «Автоматически». Файлы сборки, оставленные другими редакторами (`.aux`, `.log`, `.synctex.gz` и подобные), и папки вроде `.vscode` не импортируются, как и в Overleaf; файлы `latexmkrc` и `.bbl` сохраняются.

## Редактор

- **Сверху**: название проекта, кто сейчас в проекте, **История** и **Поделиться**.
- **Левая панель**: переключает левую область между файлами, поиском, библиографией, рецензированием, чатом и ИИ; сочетания клавиш и настройки проекта — внизу.
- **В центре**: редактор с переключателем **Код / Визуальный** на панели инструментов.
- **Справа**: PDF с кнопками **Перекомпилировать**, **Журналы**, переходом к PDF, открытием в новом окне и скачиванием.

## Компиляция и PDF

- Нажмите **Перекомпилировать** или `Mod+S` / `Mod+Enter`. Автокомпиляция включена по умолчанию и запускает сборку, когда вы делаете паузу в наборе.
- **Журналы** показывает число ошибок; откройте его, чтобы увидеть каждую ошибку с пояснением, и щёлкните ошибку, чтобы перейти к её строке. Ошибки также отмечаются рядом с номерами строк в редакторе.
- **Исходник ↔ PDF**: поставьте курсор в исходнике и нажмите кнопку с перекрестием на панели PDF — PDF прокрутится к этому месту; дважды щёлкните PDF, чтобы вернуться к исходнику.
- **PDF в отдельном окне**: «Открыть PDF в новом окне» на панели PDF позволяет вынести PDF на другой экран, пока редактор занимает всё своё окно. См. [Компиляция и PDF](#/help/compiling).
