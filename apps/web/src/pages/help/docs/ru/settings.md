# Настройки

Щёлкните свой аватар внизу слева и выберите **Настройки**.

- **Учётная запись**: ваше отображаемое имя (его видят соавторы, в комментариях и в истории) и пароль. При смене пароля можно выйти на других своих устройствах. Пароль должен содержать не менее 8 символов, в том числе заглавную букву, строчную букву и цифру; спецсимволы необязательны. Оценка, которая показывается при вводе (слабый, средний, хороший, надёжный), растёт с длиной и спецсимволами. При регистрации и сбросе пароля администратором действуют те же правила. Адрес электронной почты для входа может изменить только администратор.
- **Внешний вид**: тема («Светлая» и «Тёмная» в синих тонах, «Лес» и «Мох» в зелёных, «Сепия» и «Эспрессо» в тёплых; по умолчанию «Светлая») и язык интерфейса (14 языков, среди них English, 简体中文, 繁體中文, 日本語, 한국어, Español, Français и Deutsch; по умолчанию — язык вашего браузера). Тёмные темы применяются и к редактору; страницы PDF остаются белыми. Сохраняется в этом браузере.
- **Службы синхронизации**: подключение учётной записи Zotero (см. [Библиография](#/help/references)), создание и отзыв токенов git (см. [Файлы](#/help/files)): каждый — для Git, MCP или обоих, на чтение и запись или только на чтение, для всех ваших проектов или некоторых, со сроком действия. Используйте отдельный токен для каждого компьютера, чтобы отзывать их по отдельности.
- **ИИ-агент**: ваше использование ИИ за последние 7, 30 или 90 дней (запросы, токены, стоимость, по дням и по моделям) и остаток лимита (если у вас есть ИИ-агент), что ИИ-агентам разрешено менять от вашего имени (**Права**) и подключение собственных ИИ-агентов через **MCP** с их токенами; см. [ИИ-агент](#/help/ai).
- **Skills ИИ** (если у вас есть ИИ-агент): ваши собственные skills, встроенные skills и чат с ИИ-агентом для написания skills; см. [ИИ-агент](#/help/ai).

Настройки редактора (размер шрифта, цвета, Vim…) находятся в разделе **Настройки** внизу левой панели редактора; см. [Редактор](#/help/editor).
