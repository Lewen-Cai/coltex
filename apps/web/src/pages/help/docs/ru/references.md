# Библиография

**Библиография** на левой панели работает с файлами `.bib` проекта.

## Цитирование

**Цитировать** показывает все записи `.bib` в проекте; ищите по автору, названию, году или ключу. Щёлкните запись, чтобы вставить `\cite{key}` в позицию курсора. Ключи предлагаются и при наборе `\cite{` в редакторе.

## Поиск и добавление

На вкладке **Добавить** введите название, авторов или ключевые слова и нажмите Enter или **Поиск**: ColTex ищет в Crossref (журналы, сборники трудов, книги) и arXiv (препринты) и показывает найденное, начиная с лучших совпадений из каждого источника. **+** добавляет статью в файл `.bib`, выбранный под полем. Если arXiv знает опубликованную версию препринта, добавляется запись по DOI этой версии.

DOI (например, `10.1145/3290605.3300857`), ссылка doi.org или идентификатор arXiv добавляются сразу, без поиска (кнопка тогда называется **Добавить**).

Записи загружаются с doi.org и добавляются в конец файла с уникальным ключом; запись, которая уже есть в файле (с тем же DOI), повторно не добавляется. Проверяйте загруженные данные.

## Zotero

1. В разделе **Настройки → Службы синхронизации** введите ключ API Zotero (создаётся в настройках zotero.org; достаточно доступа на чтение). Он хранится на этом сервере в зашифрованном виде и используется только для чтения вашей библиотеки.
2. На вкладке **Zotero** панели «Библиография» выберите библиотеку или коллекцию, чтобы импортировать её в проект как файл `.bib`.
3. **Обновить** заменяет этот файл текущим содержимым Zotero, поэтому редактируйте записи в Zotero, а не в файле.

Обновление использует подключение Zotero того, кто импортировал файл.
