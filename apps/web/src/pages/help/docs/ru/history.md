# История

Кнопка **История** вверху редактора открывает просмотр истории. Он устроен как журнал git: у каждой версии есть короткий идентификатор (например, `a1b2c3d`), описание, время создания и автор.

- Версии записываются автоматически после паузы в редактировании, с указанием авторов изменений.
- **Сохранить версию** сразу записывает текущее состояние с вашим описанием (как сообщение коммита). Если с прошлой версии ничего не изменилось, описание становится её меткой.
- Выберите версию, чтобы увидеть, какие файлы и как она изменила, или сравнить её с текущим проектом.
- **Отменить эти изменения** отменяет только то, что изменила эта версия, и сохраняет всё, что изменено позже (как `git revert`). Если файл с тех пор был изменён так, что возникает конфликт, ничего не меняется, а файл называется в сообщении.
- **Восстановить проект** возвращает все файлы к состоянию этой версии; добавленные позже файлы удаляются. **Восстановить этот файл** делает то же для одного файла.
- Отмены и восстановления сами становятся версиями («Отмена a1b2c3d», «Возврат к a1b2c3d»; щёлкните идентификатор, чтобы перейти к той версии), поэтому их тоже можно отменить.
- **Добавить метку** даёт версии имя (например, «Отправлено»), чтобы потом легко её найти.
- Файлы любой версии можно скачать в виде .zip.

> Версия также сохраняется перед применением изменений ИИ, перед заменой по всему проекту, git push, отменой изменений и восстановлением.
