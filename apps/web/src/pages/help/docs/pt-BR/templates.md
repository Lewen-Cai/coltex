# Modelos

## Novos projetos a partir de modelos

Novos projetos podem começar de um modelo integrado ou de um compartilhado neste servidor; veja [Primeiros passos](#/help/getting-started).

## Publicar um projeto como modelo

O proprietário de um projeto pode publicá-lo como modelo para todos neste servidor, por exemplo para o formato de tese de um grupo:

1. No menu do projeto (⋯) na lista de projetos, ou nas configurações do projeto, escolha **Publicar como modelo…**.
2. Dê um nome e uma descrição e clique em **Publicar**.

Bom saber:

- Os novos projetos criados a partir dele recebem os arquivos do projeto como estão **naquele momento**, o compilador e o idioma da verificação ortográfica; não os membros, o histórico ou os comentários.
- O modelo acompanha o projeto: altere o projeto, e os novos projetos criados depois recebem as alterações.
- Abra **Publicar como modelo…** de novo para renomeá-lo ou **Despublicar**. Os administradores também podem remover modelos compartilhados na janela de novo projeto.
- Ele desaparece quando o projeto é excluído.

## Converter para um modelo de periódico

**Converter para modelo…** no menu de um projeto (nas configurações do projeto: "Converter para um modelo de periódico") reescreve um artigo para outro periódico ou conferência: IEEE Transactions, Conferência IEEE, Conferência ACM, Periódico ACM, Elsevier, Springer LNCS, APS (REVTeX) ou um artigo simples.

- O título, os autores, as afiliações, o resumo, os pacotes e a bibliografia são reconstruídos em um **novo projeto**, que é então compilado. O original continua como está.
- Um relatório lista o que foi alterado e o que conferir. A IA pode cuidar do que restar.
