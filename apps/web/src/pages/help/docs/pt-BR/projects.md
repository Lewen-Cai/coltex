# Projetos

## A lista de projetos

- **Área de trabalho**: todos os projetos de que você é proprietário ou membro; busque, alterne entre lista e cartões, filtre por proprietário.
- **Compartilhados comigo**: projetos para os quais outras pessoas convidaram você.

O menu de um projeto (⋯) tem: abrir, renomear (proprietários e editores), fazer uma cópia, baixar .zip, baixar PDF, converter para modelo, publicar como modelo (proprietários), arquivar e mover para a lixeira. Selecione vários projetos na lista para agir sobre eles de uma vez.

## Renomear

Proprietários e editores renomeiam um projeto com **Renomear…** no menu dele, ou clicando no nome dele no topo do editor: Enter salva, Esc cancela. Todos veem o novo nome na hora, inclusive nos editores que estão abertos.

## Etiquetas

**Etiquetas** na barra lateral organizam seus projetos; clique em uma para ver só os projetos dela. As etiquetas são só suas e nunca mudam o que os outros membros veem. Clique nas etiquetas de um projeto (a coluna Etiquetas na lista, ou no cartão; sem nenhuma, **+ Etiqueta** aparece ao passar o mouse) para marcar etiquetas ou criar uma nova, ou selecione vários projetos na lista.

## Arquivo e lixeira

- **Arquivar** tira projetos concluídos da sua lista sem alterá-los; desarquive-os quando quiser.
- Os projetos na **Lixeira** podem ser restaurados. Na lixeira, o proprietário pode **Excluir para sempre** (para todos); os outros membros usam **Sair do projeto**.

> Arquivar e mover para a lixeira mudam só a sua própria lista, até que o proprietário exclua o projeto de vez.

## Cópias

**Fazer uma cópia** cria um novo projeto seu com todos os arquivos e configurações, mas sem os colaboradores, o histórico ou os comentários. Leitores também podem fazer cópias.
