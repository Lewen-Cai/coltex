# 协作与审阅

## 邀请别人

点编辑器右上角的 **分享**：

- 只能把项目分享给在这台服务器上有账号的人。在输入框里输入对方姓名或邮箱的一部分，会列出匹配的账号，选中后选择角色，点 **+** 添加。
- 还没有账号的人需要先由管理员或系统管理员发邀请链接注册，见 [管理](#/help/admin)。
- 在成员列表里可以修改角色、转让所有权或移除成员。只有项目所有者能管理成员。

### 角色

| 角色 | 能做什么 |
| --- | --- |
| 所有者 | 全部操作，包括管理成员、删除项目、发布为模板 |
| 编辑者 | 编辑文件、管理文件、接受或拒绝修订 |
| 审阅者 | 只能以修订的形式修改，可以评论 |
| 只读 | 查看、编译、下载、评论 |

## 实时协作

多人可以同时编辑同一个文件，每个人的光标用不同颜色显示，顶部会显示正在编辑的人。修改会实时同步，不需要保存。

## 评论

选中文字后点工具栏上的评论按钮（或按 `Mod+Alt+M`），写下评论。评论显示在左侧 **审阅** 面板里，可以回复、编辑、标记为已解决。输入 `@` 可以提及别人，对方会收到通知。

## 修订（Track changes）

在审阅面板里可以打开修订：对所有人，或者只对某些人。打开后，修改不会直接改动文字，而是记为建议：

- 删除的文字显示为删除线，新增的文字高亮显示。
- 编辑者可以逐条或批量 **接受** 或 **拒绝**；点错了可以在随后弹出的提示里点 **撤销**（15 分钟内有效）。
- 审阅者的修改总是记为修订；审阅者可以在面板里 **撤回** 自己的建议。
- 自己改错了：`Ctrl/Cmd+Z` 可以撤销自己的修订；在原处把删掉的文字打回去，会直接恢复原文，而不是再记一条新的建议。
- PDF 显示的是包含所有建议的文字。

## 聊天

左侧竖栏的 **聊天** 是项目内的群聊：

- `Enter` 发送，`Shift+Enter` 换行。
- 输入 `@` 提及成员。
- 写在 `$…$` 里的公式会被排版显示，例如 `$x^2$`。

## 通知

有人在聊天或评论里 @ 你、回复你的评论，或者把你加入项目时，会出现在 **通知** 里，侧栏会显示未读数。通知只在 ColTex 内显示，不发邮件。
