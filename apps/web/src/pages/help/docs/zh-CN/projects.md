# 项目管理

## 项目列表

- **项目区**：你拥有或参与的全部项目，可以搜索，在列表和卡片视图之间切换，按所有者筛选。
- **与我共享**：别人邀请你加入的项目。

每个项目的菜单（⋯）里有：打开、重命名（所有者和编辑者）、创建副本、下载 .zip、下载 PDF、转换为模板、发布为模板（所有者）、归档、移到回收站。在列表视图里勾选多个项目，可以批量操作。

## 重命名

所有者和编辑者可以在项目菜单里点 **重命名…**，或者在编辑页顶部点项目名称直接修改：回车保存，Esc 取消。所有人会立刻看到新名称，已经打开的编辑页也一样。

## 标签

侧栏的 **标签** 用来给项目分类，点标签可以只看带这个标签的项目。标签只有你自己看得到，不会影响其他成员。点项目的标签（列表里的“标签”列，或卡片上；没有标签时鼠标移上去会出现 **+ 标签**）可以勾选标签或新建标签，也可以在列表里多选后批量添加。

## 归档和回收站

- **归档**：把已经完成的项目移出列表，内容保持不变，随时可以取消归档。
- **回收站**：移到回收站的项目可以恢复。在回收站里，所有者可以 **永久删除**（对所有人删除），其他成员则是 **退出项目**。

> 归档和回收站都只影响你自己的列表，其他成员看到的不受影响，直到所有者永久删除项目。

## 创建副本

**创建副本** 会生成一个属于你的新项目，带上全部文件和设置，但不包括协作者、历史和评论。只读成员也可以创建副本。
