# 管理

系统管理员在头像菜单的 **设置** 里能看到“管理”一组页面；管理员在那里能看到 **管理用户** 和 **邀请**，用于管理自己的小组。

## 用户和邀请

- 不开放公开注册，账号只能通过邀请链接创建。项目也只能分享给已有账号的人。
- 账号有三种角色：
  - **成员**。
  - **管理员**：带一个 **小组**，比如导师和他的学生。管理员邀请的成员会加入他的小组，管理员也只能管理这些人。
  - **系统管理员**：有且只有一个，就是首次设置时创建的账号。它负责整个实例（AI 服务、备份、网络），能看到所有人。不能再设第二个，这样某个管理员账号出问题也不会把整个系统搞崩。
- **邀请**：创建一次性邀请链接（只能用来注册一个账号），可以限定某个邮箱，也可以不填邮箱，让拿到链接的任何人使用；设置有效期。待接受的邀请在列表里点“链接”可以随时再复制，每个可访问的地址（局域网、Tailscale、Cloudflare）各有一条。系统管理员可以邀请成员或管理员，并选择新账号的 **AI 用户组**。管理员只能邀请成员进自己的小组，这些成员自动使用管理员所在的 AI 用户组。管理员只能看到和撤销自己发出的邀请。
- **管理用户**：系统管理员能看到所有账号，可以设为成员或管理员、把成员调到别的小组（行菜单里的 **小组**）、重置密码、停用或删除账号。管理员只能看到自己和自己小组的成员，也只能对这些成员重置密码、停用或删除。删除账号会删除其拥有的项目。
- 要把系统管理员交给别人（或者那个账号丢了要找回），在服务器上运行 `coltex cli system-admin <邮箱>`；原来的系统管理员会变成管理员。
- 忘了密码（包括系统管理员的）？在服务器上运行 `coltex cli reset-password <邮箱>`：它会让你输入两次新密码，并让这个账号在所有地方退出登录。

## AI 服务

- **AI 服务**：接入模型提供商，可以用 API 密钥，也可以用订阅登录（Claude Pro/Max、ChatGPT、Copilot 等），还可以接入自己部署的 OpenAI 兼容服务（Ollama、vLLM、LM Studio 等）。密钥加密保存，成员看不到，请求经过本服务器转发。
- 订阅登录时，如果页面最后跳到一个打不开的 localhost 地址，把地址栏里的完整地址复制回 ColTex 即可。
- 设置“自动”所用的三个模型后，所有人默认使用自动选择：**判断模型**（用便宜、快速的模型）读每条消息，把它交给**轻量模型**（简单问题、小修改）或**强模型**（多处错误、跨文件修改、需要仔细推敲的写作）。三个都设置好之前，大家默认使用自己有权使用的第一个模型。
- **AI 用量与权限**：查看全组和每个人的请求数与 token 用量。谁能用哪些模型通过 **AI 用户组** 管理：每个用户组设置可用的提供商（含之后新增的模型）或单个模型，比如“博士生”可以用强模型，“本科生”只用轻量模型。每个人最多属于一个用户组，可以在邀请时选好，也可以之后在人员列表里点开某人修改。不在任何用户组里的人不能使用 AI 智能体，所以新邀请的人默认没有 AI，直到系统管理员把他加入用户组（管理员邀请的成员自动使用管理员的用户组）。系统管理员总是可以使用所有模型。删除用户组后，其中的人会失去 AI 权限，直到被加入其他用户组。

  用户组还可以限制每个成员每天、每周或每月的用量：token 数、费用（按标价），或两者都限。成员用到上限后，新的消息会被拒绝，直到下一个周期开始（自然日、从周一开始的周、自然月，按服务器时区）；越过上限的那条消息仍会完成。成员可以在 AI 智能体输入框下方看到自己的用量。系统管理员不受限制。

  需要单独调整某个人时，在列表里点开他：在 **自定义** 里打开 **单独设置可用模型** 或 **单独设置用量上限**，打开时代替他所在用户组的设置（不在用户组里也可以单独给模型）。列表里会标出 **已自定义**。

## 存储与备份

- 项目文件可以存放在本地磁盘或 S3 兼容存储，通过启动时的环境变量（`STORAGE` 和 `S3_*`）设置。历史、编译输出和编译器的工作副本始终在数据目录里。
- **WebDAV 备份**：备份到 Nextcloud、ownCloud、NAS 或任意 WebDAV 服务器上的一个文件夹。每份备份是一个文件，包含数据库、所有项目文件和历史。可以设置每天或每周自动备份，并设置保留的份数。WebDAV 服务器提供“应用密码”时，建议使用应用密码。
> **加密**：加密备份（AES-256）里还包含实例密钥，恢复后已接入的 AI 服务仍然可用。**请把加密密码另外保存好，丢了就无法打开备份。**
- 恢复备份需要在服务器上停掉服务后运行命令行 `restore`，见部署文档。

## 监控

**概览** 页显示服务器、编译器和数据库的实时状态，以及 CPU、内存、编译次数的历史图表。数据由服务器每 10 秒采样一次，保留 30 天，没人打开页面时也会记录。

## 网络

**网络** 页面列出 ColTex 现在可访问的地址（邀请链接、Git 地址都会用到），可以开启自带的 Tailscale 和 Cloudflare Tunnel，并显示请求是怎样到达服务器的。详见[部署与网络](#/help/deployment)。
