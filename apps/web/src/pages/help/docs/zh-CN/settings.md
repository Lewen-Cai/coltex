# 设置

点左下角的头像，选 **设置**。

- **账户**：修改显示名称（协作者、评论和历史里显示的名字）和密码。修改密码时可以顺便退出其他设备。密码至少 8 位，必须包含大写字母、小写字母和数字，符号可选；输入时会显示强度（弱、一般、良好、强），更长或带符号的密码更强。注册和管理员重设密码也用同样的规则。登录邮箱只能由管理员修改。
- **外观**：主题（蓝色的浅色和深色、绿色的森林和苔藓、紫色的薰衣草和梅子，默认浅色）；界面语言（共 14 种，包括 English、简体中文、繁體中文、日本語、한국어、Español、Français、Deutsch 等，默认跟随浏览器的语言）。深色主题也作用于编辑器，PDF 页面始终是白色。主题保存在你的账号里，换浏览器登录也一样（登录页始终是浅色）；界面语言保存在当前浏览器里。
- **同步服务**：连接 Zotero 账户（见 [参考文献](#/help/references)），以及创建和撤销 git 令牌（见 [文件](#/help/files)）：每个令牌可以选择用于 Git、MCP 或两者，读写或只读，所有项目或部分项目，以及有效期。建议每台电脑用一个令牌，这样可以单独撤销。
- **AI 智能体**：你最近 7、30 或 90 天的 AI 用量（请求数、token、费用，按天和按模型）和剩余额度（有 AI 智能体时），AI 智能体可以替你改动什么（**权限**），以及通过 **MCP** 连接你自己的 AI 智能体和它们的令牌，见 [AI 智能体](#/help/ai)。
- **AI Skill**（有 AI 智能体时）：你自己的 Skill、内置 Skill，以及帮你写 Skill 的 AI 智能体对话框，见 [AI 智能体](#/help/ai)。

编辑器相关的设置（字号、配色、Vim 等）在编辑器左侧竖栏底部的 **设置** 里，见 [编辑器](#/help/editor)。
