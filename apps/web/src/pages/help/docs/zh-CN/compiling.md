# 编译与 PDF

## 编译器和主文档

在项目设置里选择 **编译器** 和 **主文档**：

- **自动**（新项目的默认值）：每次编译时根据文档选择。导言区（包括其中 `\input` 的文件和项目里自己的 `.sty`/`.cls`）加载了 `ctex`、`xeCJK`、`fontspec`、`unicode-math` 等，或文档类是 `ctexart`/`ctexbook` 等时用 XeLaTeX；加载 `luacode`、`luatexja` 时用 LuaLaTeX；其余用 pdfLaTeX。第一行写 `% !TEX program = xelatex` 或项目里有 `latexmkrc` 时按它们的设置。
- **pdfLaTeX**：英文文档最常用。
- **XeLaTeX**：中文（ctex）和系统字体需要用它。
- **LuaLaTeX**：同样支持系统字体。

选了具体的编译器，就总是用它，不再自动判断。

> 写中文时加上 `\usepackage[UTF8]{ctex}`（或使用 `ctexart` 文档类），自动模式就会改用 XeLaTeX。只在正文里写中文而不加载 ctex，pdfLaTeX 会报 “Unicode character … not set up for use with LaTeX”。

主文档是编译时的入口文件，在项目设置的 **主文档** 里选择。

编译使用完整的 TeX Live，由 latexmk 自动处理多次编译、BibTeX/Biber 和索引。出于安全考虑，编译在隔离的环境里进行，不能联网，shell escape 也受到限制。

## 编译选项

点 **重新编译** 旁边的下拉箭头：

- **自动编译**：停止输入一会儿后自动编译（多人同时编辑时，同一个项目每次只编译一次）。
- **编译模式**：“正常”或“快速［草稿］”。草稿模式不嵌入图片，速度更快。
- **出错时**：“遇到第一个错误就停止”或“尽量忽略错误继续编译”。
- **清除缓存并重新编译**：编译结果奇怪时，清掉辅助文件再从头编译。

这些选项按项目保存在当前浏览器里。

## 日志

**日志** 按钮上的数字是错误数。日志面板按错误、警告、排版问题分类：

- 每条显示 LaTeX 原文，常见问题附带中文说明，比如缺少宏包时会告诉你该加哪个包。
- 点一条会跳到对应文件的对应行。
- 也可以查看原始日志，或者让 AI 解释、修复错误。

> 编译失败但之前编译成功过时，PDF 栏会继续显示上一份 PDF。

## 源码和 PDF 之间定位

- **源码 → PDF**：光标放在源码里，点 PDF 栏上的 **定位**（右键菜单里的“定位到 PDF”也一样），PDF 会滚到对应位置并短暂高亮。
- **PDF → 源码**：在 PDF 上双击，编辑器会打开对应文件，跳到对应行。

## 布局：编辑器、PDF 或两者并排

PDF 栏右侧的视图切换（四个小按钮）可以选 **仅编辑器**、**编辑器和 PDF**（并排）或 **仅 PDF**，和 Overleaf 一样；第四个按钮在新窗口中打开 PDF。浏览器会记住你的选择。把中间的分隔线拖到一边，也会隐藏那一侧。

- 仅编辑器时，**重新编译** 和同样的视图切换在编辑器工具栏末尾。
- PDF 隐藏时，从编辑器“定位到 PDF”会自动切换到 PDF。
- 窗口较窄时（平板、手机）一次只显示其中一个；打开文件、搜索等侧边面板时，面板会覆盖在编辑器上。

## PDF 单独窗口

点视图切换的最后一个按钮 **在新窗口中打开 PDF**，PDF 会在一个单独的窗口里打开，可以拖到另一块屏幕：

- 编辑器窗口隐藏 PDF 栏，编辑区占满整个窗口，工具栏末尾会出现 **重新编译**。
- 新窗口里有重新编译、日志、定位和下载按钮。在新窗口的 PDF 上双击，编辑器窗口会跳到对应的源码。
- 点编辑器工具栏上的 **在此处显示 PDF**，或者关掉新窗口，PDF 栏会回到编辑器窗口。

## 下载

- PDF 栏右上角可以下载当前的 PDF。
- 文件树顶部的下载按钮会把项目源文件打包成 .zip 下载。
- 在项目列表里，项目菜单（⋯）中的 **下载 PDF** 会先编译再下载，**下载 .zip** 会下载全部源文件。

## 导出为 Word

有些期刊只收 Word 文件。项目列表中项目菜单（⋯）里的 **导出为 Word…**，或项目设置 **操作** 中的同名选项，会把项目转成 .docx。

- 标题页取自文档本身：标题、作者、单位、通讯作者、摘要和关键词。支持模板转换能读取的文档类（Springer Nature `sn-jnl`, Elsevier, Elsevier CAS, OUP, BMC, IEEE, ACM, LNCS, REVTeX, `article`）。
- 数学公式会变成 Word 公式。图和表由 Word 编号，PDF 和 EPS 图片会转成普通图片，带编号的公式保留编号，`\eqref` 仍然指向它们。
- 表格会变成可以编辑的 Word 表格，合并的单元格也保留。参考文献列表留在原来参考文献的位置，带有标题（References，或文档自己设的标题），正文里的引用可以点到对应条目。
- **引用格式**：**与文档相同** 会按文档使用的参考文献样式来选。也可以选 APA、Vancouver、AMA、IEEE、Nature 或 Chicago，或者上传到项目里的 `.csl` 文件。
- **Word 模板**：把期刊提供的 Word 模板（`.docx`）上传到项目，在这里选中它，导出的文档就会使用它的样式。项目里有 `.docx` 文件时才会出现这一项。
- 投稿前请检查结果：自定义宏和复杂表格可能需要在 Word 里再调整。TikZ 图不会被转换，请先把它们编译成图片，再用图片代替。
