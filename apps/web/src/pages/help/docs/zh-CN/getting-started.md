# 快速上手

ColTex 是部署在你们自己服务器上的协作 LaTeX 编辑器，用法和 Overleaf 基本一致：左边写源码，右边看 PDF，多人可以同时编辑同一个项目。

## 新建项目

点左上角的 **新建项目**，填写名称，再选一个模板：

| 计算机与电子工程 | IEEE 会议、IEEE 期刊、IEEE 计算机学会会议、IEEE 计算机学会期刊、IEEE 通信学会期刊、ACM 会议、ACM 期刊、ACM 投稿（匿名）、ACM SIGPLAN 会议、ACM Transactions on Graphics、Springer LNCS、PMLR 会议论文集 |

除空白文章外，每个模板都带有摘要、示例章节和 `references.bib`，可以直接编译。这些文档类都是 TeX Live 自带的官方版本。不少知名期刊和会议的模板没有内置，原因和添加方法见 [模板](#/help/templates)。

模板上方的按钮只显示某个领域的模板。共享给你的模板（比如课题组的论文格式）也在同一个列表里，标签写明是谁共享的；见 [模板](#/help/templates)。

新项目的编译器是 **自动**：每次编译时根据文档内容选择，见 [编译与 PDF](#/help/compiling)。

已有的 Overleaf 项目可以在 Overleaf 里选 **Download Source** 下载 zip，再在 ColTex 里点 **导入** 上传（最大 200 MB）。主文档会自动识别，编译器同样是自动。其他编辑器留下的编译文件（`.aux`、`.log`、`.synctex.gz` 等）和 `.vscode` 这类文件夹会被略过，和 Overleaf 一样；`latexmkrc` 和 `.bbl` 文件会保留。

## 编辑器的布局

- **顶部**：项目名、正在编辑的人、**历史版本**、**分享**。
- **左侧竖栏**：在文件、搜索、参考文献、审阅、聊天、AI 之间切换左侧面板；底部是快捷键和项目设置。
- **中间**：编辑器。上方工具栏可以切换 **代码 / 可视化** 两种模式。
- **右侧**：PDF。栏上有 **重新编译**、**日志**、定位按钮、在新窗口打开、下载。

## 编译和查看 PDF

- 点 **重新编译**，或按 `Mod+S` / `Mod+Enter`。默认开着自动编译，停止输入一会儿后会自动编译。
- 出错时 **日志** 上会显示错误数，点开可以看到每条错误和中文说明，点一条可以跳到对应的行。错误也会直接标在编辑器的行号旁边。
- **源码 ↔ PDF 定位**：光标放在源码里，点 PDF 栏上的准星按钮，PDF 会滚到对应位置并高亮；在 PDF 上双击，会跳回源码对应的行。
- **PDF 单独窗口**：点 PDF 栏右侧的“在新窗口中打开 PDF”，可以把 PDF 拖到另一块屏幕，编辑区会占满整个窗口。详见 [编译与 PDF](#/help/compiling)。
