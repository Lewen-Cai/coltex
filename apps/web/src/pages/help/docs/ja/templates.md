# テンプレート

## テンプレートから新規プロジェクトを作る

新規プロジェクトは、組み込みのテンプレート、またはこのサーバーで共有されているテンプレートから始められます。[はじめに](#/help/getting-started) を参照してください。

## プロジェクトをテンプレートとして公開する

プロジェクトのオーナーは、そのプロジェクトをこのサーバーの全員向けのテンプレートとして公開できます。研究室の学位論文の書式などに便利です。

1. プロジェクト一覧のプロジェクトのメニュー（⋯）、またはプロジェクト設定で、**テンプレートとして公開…** を選びます。
2. 名前と説明を入力し、**公開** をクリックします。

知っておくと便利なこと：

- テンプレートから作った新規プロジェクトには、**その時点** のプロジェクトのファイル、コンパイラ、スペルチェックの言語が引き継がれます。メンバー、履歴、コメントは引き継がれません。
- テンプレートは元のプロジェクトに連動します。プロジェクトを変更すると、それ以降に作られる新規プロジェクトにその変更が反映されます。
- 名前を変えたり **公開を取り消す** には、もう一度 **テンプレートとして公開…** を開きます。管理者は新規プロジェクトのダイアログで共有テンプレートを削除することもできます。
- プロジェクトが削除されると、テンプレートもなくなります。

## ジャーナルテンプレートへの変換

プロジェクトのメニューの **テンプレートに変換…**（プロジェクト設定では「ジャーナルテンプレートに変換」）は、論文を別のジャーナルや会議向けに書き換えます。対象は IEEE Transactions、IEEE 会議、ACM 会議、ACM ジャーナル、Elsevier、Springer LNCS、APS (REVTeX)、または標準の article です。

- タイトル、著者、所属、要旨、パッケージ、参考文献は **新しいプロジェクト** に作り直され、その後コンパイルされます。元のプロジェクトはそのまま残ります。
- 変更した点と確認すべき点がレポートに一覧表示されます。残った問題は AI に任せることもできます。
