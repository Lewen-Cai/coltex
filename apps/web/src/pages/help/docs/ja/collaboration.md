# 共同作業

## ユーザーを招待する

エディター右上の **共有** をクリックします。

- プロジェクトを共有できるのは、このサーバーにアカウントを持つユーザーだけです。名前またはメールアドレスの一部を入力し、一覧からアカウントを選び、ロールを選んで **+** をクリックします。
- アカウントを持っていない人は、まず管理者またはシステム管理者から招待リンクをもらう必要があります。[管理](#/help/admin) を参照してください。
- メンバー一覧では、ロールの変更、所有権の移譲、メンバーの削除ができます。メンバーを管理できるのはオーナーだけです。

### ロール

| ロール | できること |
| --- | --- |
| オーナー | メンバーの管理、プロジェクトの削除、テンプレートとしての公開を含むすべての操作 |
| 編集者 | ファイルの編集と管理、提案の承諾と却下 |
| レビュアー | 変更履歴付きの提案としてのみテキストを変更、コメント |
| 閲覧者 | 閲覧、コンパイル、ダウンロード、コメント |

## 一緒に編集する

複数のユーザーが同じファイルを同時に編集できます。カーソルは人ごとに色分けされ、ヘッダーには参加中のユーザーが表示されます。変更はリアルタイムに同期されるため、保存の操作は必要ありません。

## コメント

テキストを選択してツールバーのコメントボタンをクリックします（または `Mod+Alt+M` を押します）。コメントは左の **レビュー** パネルに表示され、返信、編集、解決ができます。`@` を入力するとユーザーをメンションでき、相手に通知が届きます。

## 変更履歴の記録

レビューパネルで、全員または一部のユーザーに対して変更履歴の記録をオンにします。すると編集は提案になります。

- 削除されたテキストには取り消し線が引かれ、新しいテキストはハイライトされます。
- 編集者は提案を 1 つずつ、またはまとめて **承諾** または **却下** します。誤って行った判断は、その後に表示されるメッセージの **元に戻す** で取り消せます（15 分間）。
- レビュアーの編集は常に記録されます。レビュアーはパネルで自分の提案を **取り下げ** できます。
- 自分のミスの場合：`Ctrl/Cmd+Z` で記録された自分の編集を元に戻せます。また、削除したテキストを元の位置に入力し直すと、新しい提案を追加するのではなく、削除が取り消されます。
- PDF には提案を反映したテキストが表示されます。

## チャット

左のレールの **チャット** はプロジェクトのチャットです。

- `Enter` で送信、`Shift+Enter` で改行します。
- `@` でメンバーをメンションします。
- `$…$` の中の数式は組版されます（例：`$x^2$`）。

## 通知

チャットやコメントでのメンション、自分のコメントへの返信、プロジェクトへの追加は **通知** に表示され、サイドバーに未読数が表示されます。通知は ColTex 内だけで、メールは送られません。
