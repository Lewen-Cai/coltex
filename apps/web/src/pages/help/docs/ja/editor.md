# エディター

## コードモードとビジュアルモード

ツールバーの **コード / ビジュアル** で編集方法を切り替えます。どちらも同じ LaTeX ソースを編集します。

- **コード**：ソースそのものを、シンタックスハイライト、オートコンプリート、括弧の対応表示付きで編集します。数式の中にカーソルがあると、組版された数式がその上に表示されます（`Esc` で隠せます）。
- **ビジュアル**：見出し、太字、リスト、数式、表、図が組版されたように表示され、カーソルのある箇所だけソースが表示されます。文章を読んだり編集したりするのに便利です。

## ツールバー

見出しレベル、太字、斜体、数式、記号、リンク、`\ref`、`\cite`、図、表、リスト、検索。収まりきらないボタンは **⋯** メニューに移ります。

- **記号**（Σ）：ギリシャ文字、演算子、矢印などがカテゴリ別に並び、クリックで挿入できます。
- **表**：挿入時にサイズを選びます。ビジュアルモードでは表をクリックするとセルを編集でき（`Tab` でセル間を移動）、表のツールバーで行や列の追加と削除、セルの結合、配置と罫線の設定ができます。
- **図**：画像をアップロードする、プロジェクトから選ぶ、またはエディターに画像を貼り付けたりドロップしたりします。ビジュアルモードでは、図の編集ボタンで幅、キャプション、ラベルを変更できます。

## オートコンプリート

`\` を入力するとコマンドの候補が表示され、`\ref{` と `\cite{` ではプロジェクトのラベルと参考文献のキーが一覧表示されます。`Ctrl+Space` でいつでも候補を表示できます。

## エラー

- **コンパイルエラー**：開いているファイルにある前回のビルドのエラーと警告は、行番号の横に点で示され、エラーには下線が引かれます。マウスを重ねると、LaTeX のメッセージと説明が表示されます。
- **コードチェック**：コンパイルせずに入力中にチェックします。閉じていない環境や対応しない環境、余分な `}` や `$`、数式の外で使われた数式コマンドなどを検出します。入力中の箇所は指摘されません。チェックを省きたい部分は `%%begin novalidate` と `%%end novalidate` で囲みます。

## スペルチェック

スペルミスのある単語には赤い点線の下線が引かれます（CJK のテキストはチェックされません）。単語を右クリックすると、候補や **辞書に追加** が表示されます。言語はプロジェクトの設定です。

辞書は、エディターのレールの下部にある **設定 → 辞書** にあります。辞書の単語は、あなたのすべてのプロジェクトで正しい綴りとして扱われます。入力欄に入力すると単語を検索でき、まだ登録されていなければ Enter で追加できます。一覧の上の文字をクリックすると、その文字の位置に移動します。**⋯** メニューでは、テキストファイルのインポート（1 行に 1 語、またはスペースやカンマ区切り。Hunspell の `.dic` ファイルも使えます）、単語の `dictionary.txt` へのエクスポート、すべての単語の削除ができます。開いているエディターはすぐに単語をチェックし直します。

## 右クリックメニュー

切り取り、コピー、貼り付け、すべて選択、削除、PDF の該当箇所へ、コメントの追加。`\ref{…}` の上では **ラベルへ移動**、`\input{…}` や `\include{…}` の上では **ファイルを開く** が表示されます。

## アウトラインとパンくずリスト

- ファイルツリーの下の **ファイルのアウトライン** には、開いているファイルの節が一覧表示されます。クリックするとその位置に移動します。カーソルのある節はハイライトされます。
- エディターの上の行には、カーソル位置の「ファイル › 節 › 小節」が表示されます。節をクリックするとその位置に移動します。エディター設定でオフにできます。

## 検索

`Mod+F`（または `Mod+Shift+F`、ツールバーの検索ボタン）を押すと、選択中のテキストが入力された状態で左に **検索** パネルが開きます。プロジェクト全体を検索し、開いているファイルの一致が先に表示されます。正規表現、大文字と小文字の区別、単語単位の検索ができ、一致を 1 件ずつまたはすべて置換できます。すべて置換する前にはバージョンが保存されます。

## エディター設定

左のレールの下部にある **設定** では、設定が左側のカテゴリにまとめられています。

- **プロジェクト**：コンパイラ、メイン文書、スペルチェックの言語（編集者が全員分を変更します）、Git の clone 用アドレス。
- **外観**：フォントサイズ、フォント（等幅またはサンセリフ）、行の高さ、**コードの配色**（GitHub、Solarized、Monokai、Dracula、Nord、One Dark など。コードモードのみ）、パンくずリスト。
- **編集**：キーバインド（デフォルト、Vim、Emacs）と、コードチェック、数式プレビュー、括弧を自動で閉じる、オートコンプリートの切り替え。
- **キーボードショートカット**：下記を参照してください。
- **操作**：単語数、コピー、Word への書き出し、テンプレートの変換、テンプレートとしての公開。

外観、編集、ショートカットの設定はあなた個人のもので、このブラウザに保存され、すべてのプロジェクトに適用されます。

## キーボードショートカット

左のレールの **ショートカット** にすべて一覧表示されます。よく使うもの：

| 操作 | キー |
| --- | --- |
| コンパイル | `Mod+S` または `Mod+Enter` |
| 元に戻す / やり直す | `Mod+Z` / `Mod+Shift+Z` |
| 検索と置換 | `Mod+F` |
| 太字 / 斜体 | `Mod+B` / `Mod+I` |
| 行をコメントアウトまたは解除 | `Mod+/` |
| 指定行へ移動 | `Mod+Alt+G` |
| 選択範囲にコメント | `Mod+Alt+M` |
| 候補を表示 | `Ctrl+Space` |

キーはお使いのシステムに合わせて表示されます。Mac では ⌘、⌥、⇧、Windows と Linux では Ctrl、Alt、Shift です。これらは既定のキーです。

### 自分でショートカットを設定する

設定の **キーボードショートカット** で、コマンドの横の **変更** をクリックし、新しいキーを押します。Ctrl（Mac では ⌘）または Alt との組み合わせが必要です。他のコマンドが使っているキーや、ブラウザと基本的な編集操作（元に戻す、コピー、貼り付け、すべて選択など）用に予約されているキーは使えません。1 つずつ、またはすべてをリセットできます。設定後は、ツールバーのヒントとショートカット一覧にあなたのキーが表示されます。
