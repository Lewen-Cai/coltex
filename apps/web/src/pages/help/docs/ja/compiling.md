# コンパイルと PDF

## コンパイラとメイン文書

プロジェクト設定に **コンパイラ** と **メイン文書** があります。

- **自動**（新規プロジェクトの既定）：ビルドのたびに文書から選ばれます。プリアンブル（`\input` で読み込むファイルや、プロジェクト内の `.sty`/`.cls` を含む）で `ctex`、`xeCJK`、`fontspec`、`unicode-math` などを読み込んでいる場合や、クラスが `ctexart`/`ctexbook` などの場合は XeLaTeX、`luacode` や `luatexja` を読み込んでいる場合は LuaLaTeX、それ以外は pdfLaTeX になります。1 行目に `% !TEX program = xelatex` がある場合や、プロジェクトに `latexmkrc` がある場合は、そちらが優先されます。
- **pdfLaTeX**：英語の文書での一般的な選択肢です。
- **XeLaTeX**：中国語（ctex）やシステムフォントに必要です。
- **LuaLaTeX**：こちらもシステムフォントに対応しています。

エンジンを選ぶと、検出は行わずに毎回そのエンジンが使われます。

> 中国語の場合は `\usepackage[UTF8]{ctex}` を読み込む（または `ctexart` クラスを使う）と、自動で XeLaTeX に切り替わります。ctex を使わない中国語のテキストは、pdfLaTeX では “Unicode character … not set up for use with LaTeX” というエラーになります。

メイン文書は、ビルドの起点となるファイルです。プロジェクト設定の **メイン文書** で選びます。

ビルドには完全な TeX Live と latexmk が使われ、LaTeX、BibTeX/Biber、索引の処理が必要な回数だけ実行されます。ビルドはネットワークにアクセスできない隔離された環境で実行され、シェルエスケープは制限されています。

## コンパイルオプション

**再コンパイル** の横の矢印には、次の項目があります。

- **自動コンパイル**：入力が止まるとビルドします（何人が入力していても、1 つのプロジェクトで同時に行うビルドは 1 つだけです）。
- **コンパイルモード**：通常 または 高速［ドラフト］。ドラフトモードは画像を省略するため、速くなります。
- **コンパイルエラー時の処理**：最初のエラーで停止するか、エラーがあってもコンパイルを試みるか。
- **キャッシュを削除して再コンパイル**：ビルド結果がおかしいときに、補助ファイルを削除して最初からビルドします。

これらはプロジェクトごとにこのブラウザに保存されます。

## ログ

**ログ** の数字はエラーの数です。ログにはエラー、警告、組版の問題が一覧表示されます。

- それぞれに LaTeX のメッセージが表示され、よくある問題には説明も付きます（たとえばパッケージが不足している場合は、追加すべきパッケージ名が示されます）。
- クリックすると、そのファイルと行に移動します。
- 生ログも確認でき、AI にエラーを説明させたり修正させたりできます。

> ビルドが失敗した場合は、最後に成功したビルドの PDF が表示されたままになります。

## ソースと PDF の間を移動する

- **ソース → PDF**：ソースにカーソルを置いた状態で PDF バーの **位置を表示** をクリックすると（または右クリックメニューの「PDF の該当箇所へ」）、PDF がその位置までスクロールしてハイライトされます。
- **PDF → ソース**：PDF をダブルクリックすると、エディターがそのファイルのその行を開きます。

## レイアウト：エディター、PDF、または両方

表示の切り替え（PDF バーの右端にある 4 つの小さなボタン）で、Overleaf と同じように **エディターのみ**、**エディターと PDF** の横並び、**PDF のみ** を切り替えられます。4 つ目のボタンは PDF を新しいウィンドウで開きます。選択はこのブラウザに記憶されます。区切り線を端までドラッグしても、その側のペインが隠れます。

- エディターのみの場合、**再コンパイル** と同じ切り替えボタンはエディターのツールバーの末尾にあります。
- エディターから **PDF の該当箇所へ** を使うと、PDF が隠れていても表示されます。
- 幅の狭いウィンドウ（タブレットやスマートフォン）では一度に 1 つしか表示できず、サイドパネル（ファイル、検索など）は開いている間エディターの上に重なります。

## PDF を別ウィンドウで表示する

**PDF を新しいウィンドウで開く**（表示切り替えの最後のボタン）を使うと、PDF が別のウィンドウで開き、別の画面に移動できます。

- エディターのウィンドウからは PDF ペインがなくなり、エディターがウィンドウいっぱいに広がります。**再コンパイル** はエディターのツールバーの末尾に移ります。
- PDF のウィンドウには、再コンパイル、ログ、PDF の該当箇所へ、ダウンロードがあります。その PDF をダブルクリックすると、エディターのウィンドウでソースに移動します。
- エディターのツールバーの **PDF をここに表示** をクリックするか、ウィンドウを閉じると、PDF ペインが戻ります。

## ダウンロード

- PDF バーから現在の PDF をダウンロードできます。
- ファイルツリーの上部にあるダウンロードボタンで、プロジェクトのソースファイルを .zip でダウンロードできます。
- プロジェクト一覧では、プロジェクトのメニュー（⋯）に、先にビルドしてからダウンロードする **PDF をダウンロード** と、すべてのソースファイルを含む **.zip をダウンロード** があります。

## Word に書き出す

Word ファイルしか受け付けないジャーナルもあります。プロジェクト一覧のプロジェクトのメニュー（⋯）、またはプロジェクト設定の **操作** にある **Word に書き出す…** で、プロジェクトを .docx に変換できます。

- タイトルページは文書から作られます。タイトル、著者、所属、責任著者、要旨、キーワードを、テンプレート変換が読み取れるクラス（Springer Nature `sn-jnl`, Elsevier, Elsevier CAS, OUP, BMC, IEEE, ACM, LNCS, REVTeX, `article`）から取り出します。
- 数式は Word の数式になります。図と表の番号は Word が付け、PDF と EPS の図は画像に変換されます。番号付きの数式は番号を保つので、`\eqref` もそのまま参照できます。
- **引用スタイル**：**文書と同じ** は文書の参考文献スタイルに合わせます。APA、Vancouver、AMA、IEEE、Nature、Chicago、またはプロジェクトにアップロードした `.csl` ファイルも選べます。
- **Word テンプレート**：ジャーナルの Word テンプレート（`.docx`）をプロジェクトにアップロードしてここで選ぶと、そのスタイルが使われます。この項目はプロジェクトに `.docx` ファイルがあるときに表示されます。
- 送る前に結果を確認してください。独自のマクロや複雑な表は Word で直す必要があるかもしれません。TikZ の図は変換されないので、先に画像にコンパイルして、その画像を使ってください。
