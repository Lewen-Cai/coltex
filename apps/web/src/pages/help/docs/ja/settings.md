# 設定

左下のアバターをクリックし、**設定** を選びます。

- **アカウント**：表示名（共同編集者、コメント、履歴に表示されます）とパスワード。パスワードを変更するときに、他のデバイスからログアウトさせることもできます。パスワードは 8 文字以上で、大文字・小文字・数字をそれぞれ含める必要があります。記号は任意です。入力中に表示される強度（弱い、普通、良い、強い）は、長さと記号によって上がります。アカウント登録や管理者によるリセットにも同じルールが適用されます。ログイン用のメールアドレスは管理者しか変更できません。
- **外観**：テーマ（青のライトとダーク、緑のフォレストとモス、暖色のセピアとエスプレッソ。既定はライト）とインターフェースの言語（14 言語。English、简体中文、繁體中文、日本語、한국어、Español、Français、Deutsch など。最初はブラウザの言語になります）。ダークテーマはエディターにも適用されますが、PDF のページは白のままです。設定はこのブラウザに保存されます。
- **同期サービス**：Zotero アカウントの接続（[参考文献](#/help/references) を参照）と、git トークンの作成と取り消し（[ファイル](#/help/files) を参照）。トークンはそれぞれ Git 用、MCP 用、または両方に使え、読み書き可能または読み取り専用、すべてのプロジェクトまたは一部のプロジェクト向けに、有効期限付きで作成できます。コンピューターごとに 1 つのトークンを使うと、個別に取り消せます。
- **AI エージェント**：過去 7 日、30 日、90 日間の AI の利用状況（リクエスト、トークン、コスト、日別およびモデル別）と利用上限の残り（AI エージェントを利用できる場合）、AI エージェントがあなたの代わりに変更できる範囲（**権限**）、そして **MCP** 経由で自分の AI エージェントを接続するための設定とそのトークン。[AI エージェント](#/help/ai) を参照してください。
- **AI Skill**（AI エージェントを利用できる場合）：自分の Skill、組み込みの Skill、Skill を書くための AI エージェントとのチャット。[AI エージェント](#/help/ai) を参照してください。

エディターの設定（フォントサイズ、配色、Vim など）は、エディターの左のレールの下部にある **設定** にあります。[エディター](#/help/editor) を参照してください。
