# 参考文献

左のレールの **参考文献** では、プロジェクトの `.bib` ファイルを扱います。

## 引用する

**引用** には、プロジェクト内のすべての `.bib` エントリが一覧表示されます。著者、タイトル、年、キーで検索できます。エントリをクリックすると、カーソル位置に `\cite{key}` が挿入されます。エディターで `\cite{` と入力したときにもキーの候補が表示されます。

## 検索して追加する

**追加** タブでタイトル、著者、キーワードを入力して Enter を押すか **検索** をクリックすると、ColTex が Crossref（ジャーナル、会議録、書籍）と arXiv（プレプリント）を検索し、見つかったものをそれぞれ一致度の高い順に一覧表示します。**+** をクリックすると、入力欄の下で選んだ `.bib` ファイルに論文が追加されます。arXiv が出版版を把握しているプレプリントは、その出版版の DOI で追加されます。

DOI（例：`10.1145/3290605.3300857`）、doi.org のリンク、arXiv ID は、検索せずに直接追加されます（このときボタンの表示は **追加** になります）。

エントリは doi.org から取得され、重複しないキーを付けてファイルの末尾に追加されます。ファイルにすでにある（同じ DOI の）エントリは二重に追加されません。取得された内容を確認してください。

## Zotero

1. **設定 → 同期サービス** で Zotero の API キー（zotero.org の設定で作成します。読み取りアクセスで十分です）を入力します。キーはこのサーバーに暗号化して保存され、ライブラリの読み取りにのみ使われます。
2. 参考文献パネルの **Zotero** タブで、ライブラリまたはコレクションを選び、プロジェクト内の `.bib` ファイルとしてインポートします。
3. **更新** すると、そのファイルが現在の Zotero の内容で置き換えられます。エントリはファイルではなく Zotero で編集してください。

更新には、そのファイルをインポートしたユーザーの Zotero 接続が使われます。
