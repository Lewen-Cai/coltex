# はじめに

ColTex は、自分たちのサーバーで動く共同編集型の LaTeX エディターです。使い方は Overleaf とほぼ同じで、左にソース、右に PDF が表示され、複数のユーザーが同じプロジェクトを同時に編集できます。

## 新規プロジェクト

左上の **新規プロジェクト** をクリックし、名前を付けてテンプレートを選びます。

| テンプレート | クラス |
| --- | --- |
| 空の論文 | 標準の `article`。最もシンプルな出発点 |
| arXiv プレプリント | `article`、1 段組、所属付きの著者（authblk）、natbib による参考文献 |
| IEEE 会議 / IEEE ジャーナル | `IEEEtran` の会議モード / ジャーナルモード |
| ACM 会議 / ACM ジャーナル | `acmart` の sigconf / acmsmall |
| Springer LNCS | `llncs`。LNCS およびその他の Springer 論文集向け |
| Elsevier ジャーナル | `elsarticle`、1 段組のプレプリント |
| APS (REVTeX 4.2) | `revtex4-2`。Physical Review および AIP のジャーナル向け |

空の論文以外は、要旨、キーワード、数式、図、表、`references.bib` が入っており、そのままビルドできます。クラスはすべて TeX Live に含まれる公式のものです。毎年新しいスタイルファイルを公開する会議（NeurIPS、ICML）は TeX Live に含まれていません。その年のファイルをプロジェクトにアップロードし、テンプレートとして公開してください。

ユーザーがテンプレートとして公開したプロジェクト（研究室の学位論文の書式など）は、「このサーバーで共有」の下に表示されます。

新規プロジェクトは **自動** でコンパイルされます。エンジンはビルドのたびに文書から選ばれます。[コンパイルと PDF](#/help/compiling) を参照してください。

Overleaf からプロジェクトを移すには、Overleaf で **Download Source** を選び、その zip をこちらで **インポート** します（最大 200 MB）。メイン文書は自動で検出され、コンパイラも自動になります。

## エディター

- **上部**：プロジェクト名、参加中のユーザー、**履歴**、**共有**。
- **左のレール**：左パネルをファイル、検索、参考文献、レビュー、チャット、AI の間で切り替えます。下部にはキーボードショートカットとプロジェクト設定があります。
- **中央**：エディター。ツールバーに **コード / ビジュアル** があります。
- **右側**：PDF。**再コンパイル**、**ログ**、PDF の該当箇所へ移動するボタン、新しいウィンドウで開くボタン、ダウンロードボタンがあります。

## コンパイルと PDF

- **再コンパイル** をクリックするか、`Mod+S` / `Mod+Enter` を押します。自動コンパイルは既定でオンになっており、入力が止まるとビルドされます。
- **ログ** にはエラーの数が表示されます。開くと各エラーが説明付きで表示され、クリックするとその行に移動します。エラーはエディターの行番号の横にも表示されます。
- **ソース ↔ PDF**：ソースにカーソルを置いた状態で PDF バーの十字アイコンをクリックすると、PDF がその位置までスクロールします。PDF をダブルクリックするとソースに戻ります。
- **PDF を別ウィンドウで**：PDF バーの「PDF を新しいウィンドウで開く」を使うと、エディターをウィンドウいっぱいに表示したまま、PDF を別の画面に置けます。[コンパイルと PDF](#/help/compiling) を参照してください。
