# AI エージェント

左のレールの **AI** で AI エージェントが開きます。管理者がモデルのサービスを接続し、あなたを AI グループに追加すると利用できるようになります。どのモデルを使えるかはグループによって決まります。

## できること

- LaTeX に関する質問に答え、選択したコードを説明します。
- コンパイルエラーを説明または修正します（ログにも「AI で修正」ボタンがあります）。
- 選択範囲を書き直す、推敲する、翻訳する。
- プロジェクトの概要を示す、参照されていないラベルを見つける、などなど。

開いているファイル、選択範囲、最近のコンパイルエラーはメッセージに添付されます。添付をクリックすると除外できます。

## 権限

AI エージェントが何を変更できるかはあなたが決めます。**設定 → AI エージェント**、またはパネル下部のモデル選択（思考レベルの下）で選んでください。メッセージ入力欄の下の行に現在の設定が表示されます。同じ設定は、MCP 経由で接続した自分のエージェントにも適用されます（下記参照）。

- **手動**（既定）：AI エージェントの変更は下書きに入り、あなたが適用するまで何も変わりません。
  1. 処理が終わると下書きがテストコンパイルされ、エラーが増えるかどうかが表示されます。
  2. **変更をレビュー** でファイルごとの差分が表示されます。一部だけを適用することもできます。
  3. **適用** すると変更がプロジェクトに書き込まれ、コンパイルされます。ビルド結果が悪化した場合はロールバックされます。適用の前にバージョンが保存されます。
  4. 適用後に **元に戻す** を使うと、その間に他のユーザーが行った編集を残したまま、変更を取り消せます。
- **自動**：AI エージェントが回答を終えるとすぐに下書きが適用されます。安全策は同じで、先にバージョンが保存され、プロジェクトがコンパイルされ、ビルド結果が悪化すればロールバックされ、適用後には **元に戻す** が使えます。その間に誰かが同じ行を変更していた場合は何も適用されず、下書きはあなたの判断を待ちます。AI エージェントを停止した場合も、下書きはあなたの判断を待ちます。
- **フルアクセス**：「自動」に加えて、AI エージェントはファイルの削除、移動、名前の変更もできます。これらは下書きではなくすぐに実行されます。各回答の最初の操作の前にバージョンが保存されます。回答には、変更したファイルとともにこれらの操作が一覧表示されます。

閲覧者とレビュアーも AI エージェントに質問できますが、AI エージェントがその人のために何かを変更することはできません。

## ウェブ

ウェブ検索が設定されると、AI エージェントはウェブを検索してページを読めます。ジャーナルの最新の投稿規定、パッケージのリリースノート、主張の出典の確認などです。Anthropic、OpenAI、ChatGPT のモデルは組み込みの検索を使い、それ以外のモデルは管理者が接続した検索サービスを使います。検索した内容と読んだページは会話にステップとして表示され、回答ではどのページに基づくかを示します。

プロジェクトの内容がこの経路で外に出ないように:
- 検索語は管理者が選んだ検索サービス（またはモデル内蔵の検索）にだけ送られ、長さは最大 128 文字です。
- 読めるのは、あなたが会話で書いたアドレスか、検索結果に出たアドレスだけで、一字一句そのままに限ります。アドレスを自分で作ることはできません。
- 読むだけです。何もアップロードや送信はしません。

ウェブページは誰でも書けるため、AI エージェントを誤らせる指示が含まれていることがあります。そのため、ウェブを使える間は、**自動** や **フルアクセス** でも AI エージェントの変更は常にあなたの確認を待ち、ファイルの削除や移動もしません。AI ツール（MCP）にはあなたの権限がそのまま適用されます。

## モデルと思考

- パネルの下部でモデルを選びます。**自動** にすると、質問に応じて ColTex が軽量モデルまたは高性能モデルを選びます。
- 思考できるモデルでは、同じ選択メニューで思考レベルを設定します。メッセージ入力欄の下の行に表示されます。

## チャットとコンテキスト

- 会話はプロジェクトごとにあなた用に保存されます（他の人には見えません）。**新しいチャット** で別のチャットを始め、**チャット履歴** で過去のチャットを一覧表示して、開く、名前を変更する、削除することができます。チャットを開き直すと、中断したところから続けられます。適用していない下書きは保持されないため、下書きがあるチャットから切り替えるときは確認が表示されます。
- メッセージ入力欄の下のリングは、チャットがモデルのコンテキストウィンドウをどれだけ使っているかを示します（例：`12k / 200k`）。70% で黄色、90% で赤になります。
- AI グループに利用上限がある場合は、その横のバーにその日、週、または月の利用量が表示されます（マウスを重ねると詳細が表示されます）。上限に達すると、次の期間までメッセージは送信できません。**設定 → AI エージェント** で過去 30 日間の利用状況と残りを確認できます。
- メッセージ入力欄で `/` を入力するとコマンドが使えます。
  - `/compact`：これまでのチャットを要約し、その要約から続けてコンテキストを空けます。メッセージは表示されたままで、AI エージェントは要約を通じて内容を覚えています。
  - `/new`：新しいチャットを始めます。
  - `/chats`：過去のチャット。
- 入力欄は入力した内容に合わせて高くなります。上端をドラッグすると高くでき（このブラウザーで記憶され、プロジェクトのチャットも同じです）、上端をダブルクリックすると元に戻ります。

## Skill

Skill とは、繰り返し行う作業のための指示をまとめたものです。たとえば「要旨をジャーナルの字数制限まで短くする」や「すべての図が参照されているか確認する」などです。Skill は Agent Skills 形式（名前、説明、指示を含む `SKILL.md`）を使うため、他の AI エージェント向けに書かれた Skill もここで使えます。

- **マイ Skill** は **設定 → AI Skill** にあり、あなただけに表示され、すべてのプロジェクトで使えます。
- 手元の Skill は **インポート** で追加します。**ファイルをアップロード** では `SKILL.md` とその参照ファイル、または Skill のフォルダーをまとめた `.zip` を、**フォルダーをアップロード** では Skill のフォルダー、または複数の Skill を含むフォルダーを取り込めます。Skill 内のスクリプトは AI エージェントが読めるテキストとして保持され、Skill の内容が実行されることは一切ありません。
- Skill を使うには、`/` を入力して Skill を選び、続けてメッセージを入力します（`/polish-abstract keep it under 200 words`）。AI エージェントは説明も読んでおり、依頼内容に合う Skill があれば自分で読み込みます。
- AI エージェントに何かを Skill にするよう頼むこともできます（「今の参考文献の直し方を Skill として保存して」）。AI エージェントがチャット内に下書きを作り、あなたはそれを編集したり、マイ Skill に保存したりできます。
- **設定 → AI Skill** では、左側にあなたの Skill が一覧表示されます。Skill を選ぶと指示と参照ファイルを読めます。**AI で作成** を選ぶと、Skill を書くための AI エージェントとのチャットが開きます（自分の Skill で **チャットで改善** を選ぶと、その Skill についてのメッセージから始まります）。このチャットは組み込みの **skill-creator** Skill に従い、Skill の使い方を尋ね、（役立つ場合は参照ファイル付きで）下書きを作り、貼り付けたテキストで下書きを試すこともできます。下書きはあなたが保存したときだけ保存されます。すでに使っている名前で保存しようとすると、置き換える前に確認が表示されます。チャットは新しいチャットを始めるまで保持されます。
- ColTex には組み込みの Skill が付属しています（**組み込み** の下に一覧表示されます）。読んだりダウンロードしたりはできますが、変更はできません。同じ名前の自分の Skill がある場合は、そちらが使われます。
  - **skill-creator**：Skill の作成（Skill のチャットはこれに従います）。

## 自分の AI ツール（MCP）

Claude Code、Codex、Cursor、VS Code（Copilot）、Windsurf、Gemini CLI、Cline、OpenCode などの AI ツールは、あなたのプロジェクトを直接操作できます。プロジェクトの一覧表示、ファイルの読み取りと検索、編集、コンパイルとログの読み取り、履歴の確認、コメントの読み取り・追加・返信ができます。ColTex はこれらのツールの MCP サーバーとして動作し、すべてのプロジェクトに共通の 1 つのアドレスを持ちます。どのプロジェクトを操作するかはツールが指定します。

**設定 → AI エージェント** の **お使いの AI ツール（MCP）** で、左側からツールを選び、3 つの手順に従います。アドレス、トークン（**トークンを作成**。表示されるのは一度だけです）、そして両方が入力済みのコピー用の設定です。トークン用のヘッダーを付けて HTTP で MCP サーバーに接続できるツールであれば、他のツールでも使えます（**その他**）。OAuth でログインするサーバーしか受け付けないアプリ（Claude や ChatGPT のカスタムコネクタなど）は、まだ接続できません。

ツールが変更できる範囲は、**設定 → AI エージェント** の権限に従います。

- **手動**（既定）：ツールの編集はあなたの提案になり、あなたや共同編集者が **レビュー** で承諾または却下します。新しいファイルは直接作成されます。
- **自動**：ツールの編集はあなた自身の編集として直接適用されます。あなたに対して変更履歴の記録がオンになっている場合は、いずれにしても提案になります。
- **フルアクセス**：「自動」に加えて、ファイルの削除、移動、名前の変更もできます。

ツールがしばらくぶりに変更を行う前には、プロジェクトの状態がバージョンとして保存されるため、元に戻せます。レビュアーのツールは変更を提案することしかできず、閲覧者のツールは閲覧とコメントしかできません。

### 安全性

- あなたのトークンを持っている人は誰でも、あなたとして操作できます。パスワードと同じように管理し、不要になったらトークン一覧で取り消してください（ツールやコンピューターごとに 1 つのトークンを使うと簡単です）。作成時には、各トークンに必要な権限だけを与えてください。
  - **用途**：Git、MCP、または両方。MCP 専用に作ったトークンでは clone や push はできず、その逆も同様です。
  - **アクセス**：**読み取り専用** にすると、あなたの権限設定にかかわらず、ツールは一覧表示、読み取り、検索、コンパイルはできますが、ファイルやコメントは変更できません（git では clone と pull はできますが、push はできません）。
  - **プロジェクト**：すべてのプロジェクト、または選んだプロジェクトだけ。それ以外のプロジェクトはトークンからは存在しないものとして扱われます。
  - **有効期限**：30 日、90 日、1 年、または無期限。期限切れのトークンは使えなくなります。取り消して新しいトークンを作成してください。
- ColTex はあなたのツールに応答するだけで、他の MCP サーバーに接続することはありません。ツールが他に何をできるか（Playwright MCP を使ったブラウザ操作、ターミナル、他のサービスなど）は、ツールとその設定次第です。プロジェクトの本文、コメント、ログは共同編集者が書くこともできるため、それらを読んだツールが、その文章の中で他の機能を使って何かをするよう指示される可能性があります。ColTex はツールに対して、プロジェクトの内容を指示ではなく内容として扱うよう伝えますが、それを守らせることができるのはツール自身だけです。ColTex 以外での操作についてはツール自身の確認機能をオンにしておき、ツールがブラウザやターミナルも使える場合は **手動** を使ってください。
- ColTex にログインしたブラウザを使えるツールは、MCP ではなく Web ページを通じて、あなたの全権限で操作します。そのため、上記の権限はそこでは制限になりません。そうしたツールには、ログインしていないブラウザプロファイルを使わせてください。
