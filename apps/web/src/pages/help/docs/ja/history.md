# 履歴

エディター上部の **履歴** で履歴ビューが開きます。git log のように、各バージョンには短い ID（`a1b2c3d` など）、説明、作成日時、作成者があります。

- バージョンは編集が一段落すると自動で記録され、誰が変更したかも残ります。
- **バージョンを保存** は、現在の状態をあなたの説明（コミットメッセージのようなもの）付きで今すぐ記録します。前回のバージョンから何も変わっていない場合は、説明がそのバージョンのラベルになります。
- バージョンを選択すると、どのファイルがどう変わったかを確認したり、現在のプロジェクトと比較したりできます。
- **これらの変更を取り消す** は、そのバージョンで行われた変更だけを取り消し、それ以降の変更はすべて残します（`git revert` と同様）。その後にファイルが衝突する形で変更されている場合は、何も変更せず、そのファイル名を表示します。
- **プロジェクトを復元** は、すべてのファイルをそのバージョンの状態に戻します。それ以降に追加されたファイルは削除されます。**このファイルを復元** は、1 つのファイルについて同じことを行います。
- 取り消しと復元もそれぞれ 1 つのバージョンになるため（「a1b2c3d を取り消し」「a1b2c3d に復元」。ID をクリックするとそのバージョンに移動します）、これらも元に戻せます。
- **ラベルを追加** でバージョンに名前（例：「投稿済み」）を付けると、後で見つけやすくなります。
- どのバージョンのファイルも .zip でダウンロードできます。

> AI の変更を適用する前、プロジェクト全体の置換、git push、取り消し、復元の前にも、バージョンが保存されます。
