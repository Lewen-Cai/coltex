# プロジェクト

## プロジェクト一覧

- **ワークスペース**：あなたが所有している、またはメンバーになっているすべてのプロジェクト。検索、リスト表示とカード表示の切り替え、オーナーでの絞り込みができます。
- **共有されたプロジェクト**：他のユーザーから招待されたプロジェクト。

プロジェクトのメニュー（⋯）には、開く、コピーを作成、.zip をダウンロード、PDF をダウンロード、テンプレートに変換、テンプレートとして公開（オーナーのみ）、アーカイブ、ゴミ箱に移動があります。一覧で複数のプロジェクトを選択すると、まとめて操作できます。

## タグ

サイドバーの **タグ** でプロジェクトを整理できます。タグをクリックすると、そのタグのプロジェクトだけが表示されます。タグはあなただけのもので、他のメンバーの表示には影響しません。プロジェクトのタグ（一覧のタグ列、またはカード上。タグがない場合はマウスを重ねると **+ タグ** が表示されます）をクリックして、タグにチェックを付けたり新しいタグを作ったりできます。一覧で複数選択してまとめて付けることもできます。

## アーカイブとゴミ箱

- **アーカイブ** すると、完了したプロジェクトを変更せずに一覧から外せます。いつでもアーカイブを解除できます。
- **ゴミ箱** のプロジェクトは復元できます。ゴミ箱から、オーナーは **完全に削除**（全員に対して）でき、他のメンバーは **プロジェクトから退出** します。

> アーカイブとゴミ箱が変えるのは自分の一覧だけです。オーナーがプロジェクトを完全に削除するまでは、他の人には影響しません。

## コピー

**コピーを作成** すると、すべてのファイルと設定を含む新しいプロジェクトがあなたのものとして作られます。共同編集者、履歴、コメントは含まれません。閲覧者もコピーを作成できます。
