# ファイル

## ファイルツリー

- ヘッダーのボタン：新規ファイル、新規フォルダー、アップロード、リンクファイルを追加。
- ファイルをフォルダーにドラッグすると移動し、名前をダブルクリックすると名前を変更できます。コンピューターからドロップしたファイルはアップロードされます。
- ファイルやフォルダーを右クリックすると、作成、アップロード、名前の変更、削除ができます。
- ファイルの横の色付きの点は、他のユーザーがそのファイルを開いていることを示します。

削除したファイルは履歴から元に戻せます。

## リンクファイル

リンクファイルは別の場所から取り込んだファイルで、いつでも元のソースから更新できます。

- **別のプロジェクトから**：別のプロジェクトの任意のファイル、またはそのコンパイル済み PDF（先にビルドされます）。共有の図や共有の `.bib` に便利です。あるプロジェクトの PDF を別のプロジェクトで図として使うこともできます。
- **URL から**：公開アドレスからダウンロードします（最大 50 MB）。ローカルネットワークやプライベートネットワーク上のアドレスは使えません。

> リンクファイルはツリーにリンクのマークが付き、マウスを重ねると取得元が表示されます。右クリックして **リンクファイルを更新** を選ぶと、再取得して置き換えます。追加や更新には、元のプロジェクトへのあなた自身のアクセス権が必要です。

## Git

どのプロジェクトも git で clone、pull、push できます。

1. **設定 → 同期サービス** で Git 用のトークンを作成します（表示されるのは一度だけなので、保管してください）。**読み取り専用** のトークンでは clone と pull はできますが、push はできません。
2. プロジェクト設定から clone 用のアドレスをコピーし、`git clone <address>` を実行します。git に求められたら、ユーザー名は任意のものを、パスワードにはトークンを入力します。
3. ローカルでコミットして `git push` すると、変更はすぐにプロジェクトに反映され、共同編集者にも表示されます。

知っておくと便利なこと：

- 各プロジェクトのブランチは `main` の 1 つだけです。
- 最後に pull した後で誰かがプロジェクトを変更していると、git は push を拒否します。先に `git pull` してから、もう一度 push してください。
- push が反映される前に、プロジェクトの状態がバージョンとして保存されます。
- レビュアーと閲覧者は push できません。
- 毎回トークンを入力しないようにするには：`git config --global credential.helper store`（Mac では `osxkeychain`）。
