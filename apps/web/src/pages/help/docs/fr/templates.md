# Modèles

## Nouveaux projets à partir de modèles

Un nouveau projet peut partir d’un modèle intégré ou d’un modèle partagé sur ce serveur ; voir [Premiers pas](#/help/getting-started).

## Publier un projet comme modèle

Le propriétaire d’un projet peut le publier comme modèle pour tout le monde sur ce serveur, pour le format de thèse d’une équipe, par exemple :

1. Dans le menu du projet (⋯) de la liste des projets, ou dans les paramètres du projet, choisissez **Publier comme modèle…**.
2. Donnez-lui un nom et une description, puis cliquez sur **Publier**.

Bon à savoir :

- Les nouveaux projets créés à partir du modèle reçoivent les fichiers du projet tels qu’ils sont **à ce moment-là**, son compilateur et sa langue de vérification orthographique ; pas ses membres, son historique ni ses commentaires.
- Le modèle suit le projet : modifiez le projet, et les nouveaux projets créés ensuite reçoivent les modifications.
- Rouvrez **Publier comme modèle…** pour le renommer ou le **Dépublier**. Les administrateurs peuvent aussi retirer des modèles partagés dans la boîte de dialogue de nouveau projet.
- Il disparaît quand le projet est supprimé.

## Convertir vers un modèle de revue

**Convertir vers un modèle…** dans le menu d’un projet (dans les paramètres du projet : « Convertir vers un modèle de revue ») réécrit un article pour une autre revue ou conférence : IEEE Transactions, conférence IEEE, conférence ACM, revue ACM, Elsevier, Springer LNCS, APS (REVTeX) ou un article simple.

- Le titre, les auteurs, les affiliations, le résumé, les packages et la bibliographie sont reconstruits dans un **nouveau projet**, qui est ensuite compilé. L’original reste tel quel.
- Un rapport liste ce qui a été modifié et ce qu’il faut vérifier. L’IA peut se charger de ce qui reste.
