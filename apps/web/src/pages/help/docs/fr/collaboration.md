# Collaboration

## Inviter des personnes

Cliquez sur **Partager** en haut à droite de l’éditeur :

- Les projets ne sont partagés qu’avec des personnes qui ont un compte sur ce serveur. Saisissez une partie d’un nom ou d’un e-mail, choisissez le compte dans la liste, choisissez un rôle et cliquez sur **+**.
- Les personnes sans compte ont d’abord besoin d’un lien d’invitation d’un administrateur ou de l’administrateur système ; voir [Administration](#/help/admin).
- Changez les rôles, transférez la propriété ou retirez des personnes dans la liste des membres. Seul le propriétaire gère les membres.

### Rôles

| Rôle | Peut |
| --- | --- |
| Propriétaire | Tout, y compris gérer les membres, supprimer le projet et le publier comme modèle |
| Éditeur | Modifier et gérer les fichiers, accepter ou refuser les suggestions |
| Relecteur | Modifier le texte uniquement par des suggestions suivies ; commenter |
| Lecteur | Lire, compiler, télécharger, commenter |

## Modifier ensemble

Plusieurs personnes peuvent modifier le même fichier en même temps ; chaque curseur a sa propre couleur et l’en-tête montre qui est présent. Les modifications se synchronisent en direct ; il n’y a rien à enregistrer.

## Commentaires

Sélectionnez du texte et cliquez sur le bouton de commentaire dans la barre d’outils (ou appuyez sur `Mod+Alt+M`). Les commentaires se trouvent dans le panneau **Relecture** à gauche, où vous pouvez y répondre, les modifier et les résoudre. Tapez `@` pour mentionner quelqu’un ; la personne reçoit une notification.

## Suivi des modifications

Dans le panneau Relecture, activez le suivi des modifications pour tout le monde ou pour certaines personnes. Les modifications deviennent alors des suggestions :

- le texte supprimé est barré et le nouveau texte surligné ;
- les éditeurs les **acceptent** ou les **refusent**, une par une ou toutes à la fois ; une décision prise par erreur peut être reprise avec **Annuler** dans le message qui suit (pendant 15 minutes) ;
- les modifications des relecteurs sont toujours suivies ; ils peuvent **retirer** leurs propres suggestions dans le panneau ;
- vos propres erreurs : `Ctrl/Cmd+Z` annule vos modifications suivies, et retaper un texte que vous avez supprimé, à son emplacement, le rétablit au lieu d’ajouter une nouvelle suggestion ;
- le PDF montre le texte avec les suggestions incluses.

## Discussion

**Discussion** dans la barre latérale gauche est la discussion du projet :

- `Enter` envoie, `Shift+Enter` passe à la ligne.
- `@` mentionne un membre.
- Les maths entre `$…$` sont composées, p. ex. `$x^2$`.

## Notifications

Les mentions dans la discussion ou les commentaires, les réponses à vos commentaires et l’ajout à un projet apparaissent dans **Notifications**, avec le nombre de non lues dans la barre latérale. Elles restent dans ColTex ; aucun e-mail.
