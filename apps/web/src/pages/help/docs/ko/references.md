# 참고문헌

왼쪽 레일의 **참고문헌**에서 프로젝트의 `.bib` 파일을 다룹니다.

## 인용하기

**인용**에는 프로젝트의 모든 `.bib` 항목이 나열되며, 저자, 제목, 연도 또는 키로 검색할 수 있습니다. 항목을 클릭하면 커서 위치에 `\cite{key}`가 삽입됩니다. 편집기에서 `\cite{`를 입력해도 키가 추천됩니다.

## 검색하고 추가하기

**추가** 탭에서 제목, 저자 또는 키워드를 입력하고 Enter를 누르면 ColTex가 Crossref(저널, 학회 논문집, 도서)와 arXiv(프리프린트)를 검색해 각각 가장 잘 맞는 결과부터 보여 줍니다. **+** 버튼을 누르면 입력란 아래에서 고른 `.bib` 파일에 논문이 추가됩니다. arXiv가 출판본을 알고 있는 프리프린트는 그 출판본의 DOI로 추가됩니다.

DOI(예: `10.1145/3290605.3300857`), doi.org 링크 또는 arXiv ID는 검색 없이 바로 추가됩니다.

항목은 doi.org에서 가져와 고유한 키로 파일 끝에 추가됩니다. 파일에 이미 있는 항목(같은 DOI)은 두 번 추가되지 않습니다. 가져온 내용은 확인하세요.

## Zotero

1. **설정 → 동기화 서비스**에서 Zotero API 키를 입력합니다(zotero.org 설정에서 만들며, 읽기 권한이면 충분합니다). 키는 이 서버에 암호화되어 저장되고 라이브러리를 읽는 데만 사용됩니다.
2. 참고문헌 패널의 **Zotero** 탭에서 라이브러리나 컬렉션을 골라 프로젝트의 `.bib` 파일로 가져옵니다.
3. **Zotero에서 새로 고침**은 그 파일을 현재 Zotero에 있는 내용으로 바꿉니다. 따라서 항목은 파일이 아니라 Zotero에서 편집하세요.

새로 고침에는 파일을 가져온 사람의 Zotero 연결이 사용됩니다.
