# 편집기

## 코드 모드와 비주얼 모드

도구 모음의 **코드 / 비주얼**로 편집 방식을 전환합니다. 두 모드 모두 같은 LaTeX 소스를 편집합니다.

- **코드**: 소스 자체를 구문 강조, 자동 완성, 괄호 짝 맞춤과 함께 편집합니다. 커서가 수식 안에 있으면 조판된 수식이 그 위에 표시됩니다(`Esc`로 숨김).
- **비주얼**: 제목, 굵게, 목록, 수식, 표, 그림이 조판된 모습으로 보이며, 커서가 있는 곳만 소스가 보입니다. 텍스트를 읽고 편집하기에 좋습니다.

## 도구 모음

제목 수준, 굵게, 기울임꼴, 수식, 기호, 링크, `\ref`, `\cite`, 그림, 표, 목록, 검색이 있습니다. 공간이 부족한 버튼은 **⋯** 메뉴로 들어갑니다.

- **기호**(Σ): 그리스 문자, 연산자, 화살표 등을 분류별로 보여 줍니다. 클릭하면 삽입됩니다.
- **표**: 삽입할 때 크기를 고릅니다. 비주얼 모드에서는 표를 클릭해 셀을 편집하며(`Tab`으로 셀 간 이동), 표 도구 모음으로 행과 열을 추가하거나 삭제하고, 셀을 병합하고, 정렬과 테두리를 설정합니다.
- **그림**: 이미지를 업로드하거나, 프로젝트에서 고르거나, 편집기에 이미지를 붙여넣거나 끌어다 놓습니다. 비주얼 모드에서는 그림의 편집 버튼으로 너비, 캡션, 레이블을 바꿉니다.

## 자동 완성

`\`를 입력하면 명령이 추천되고, `\ref{`와 `\cite{`를 입력하면 프로젝트의 레이블과 참고문헌 키가 나열됩니다. `Ctrl+Space`를 누르면 언제든지 추천 항목이 열립니다.

## 오류

- **컴파일 오류**: 마지막 빌드에서 열린 파일에 생긴 오류와 경고는 줄 번호 옆에 점으로 표시되고, 오류에는 밑줄이 그어집니다. 마우스를 올리면 LaTeX 메시지와 설명이 보입니다.
- **코드 검사**: 컴파일하지 않고 입력하는 동안 검사합니다. 닫히지 않았거나 짝이 맞지 않는 환경, 남는 `}`나 `$`, 수식 밖의 수식 명령 등을 찾습니다. 지금 입력 중인 곳은 표시하지 않습니다. 검사를 건너뛸 부분은 `%%begin novalidate`와 `%%end novalidate`로 감싸세요.

## 맞춤법 검사

철자가 틀린 단어에는 빨간 점선 밑줄이 그어집니다(CJK 텍스트는 검사하지 않음). 단어를 마우스 오른쪽 버튼으로 클릭하면 추천 단어나 **사전에 추가**가 나옵니다. 언어는 프로젝트 설정입니다.

내 사전은 편집기 레일 아래쪽의 **설정 → 사전**에 있으며, 사전의 단어는 내 모든 프로젝트에서 올바른 단어로 처리됩니다. 입력란에 입력해 단어를 찾고, 아직 없으면 Enter를 눌러 추가합니다. 목록 위의 글자를 누르면 그 글자로 이동합니다. **⋯** 메뉴에서 텍스트 파일 가져오기(한 줄에 한 단어, 또는 공백이나 쉼표로 구분. Hunspell `.dic` 파일도 가능), 단어를 `dictionary.txt`로 내보내기, 모두 제거를 할 수 있습니다. 열려 있는 편집기는 바로 단어를 다시 검사합니다.

## 오른쪽 클릭 메뉴

잘라내기, 복사, 붙여넣기, 모두 선택, 삭제, PDF에서 위치 보기, 댓글 추가가 있습니다. `\ref{…}` 위에서는 **레이블로 이동**을, `\input{…}`이나 `\include{…}` 위에서는 **파일 열기**를 제공합니다.

## 개요와 이동 경로

- 파일 트리 아래의 **파일 개요**에는 열린 파일의 절이 나열되며, 클릭하면 그곳으로 이동합니다. 현재 위치한 절이 강조 표시됩니다.
- 편집기 위의 줄에는 커서 위치의 "파일 › 절 › 소절"이 표시되며, 절을 클릭하면 그곳으로 이동합니다. 편집기 설정에서 끌 수 있습니다.

## 검색

`Mod+F`(또는 `Mod+Shift+F`, 도구 모음의 검색 버튼)를 누르면 선택한 텍스트가 채워진 채 왼쪽에 **검색** 패널이 열립니다. 열린 파일의 결과를 먼저 보여 주며 프로젝트 전체를 검색하고, 정규식, 대소문자 구분, 단어 단위 일치를 지원하며, 일치 항목을 하나씩 또는 모두 바꿉니다. 모두 바꾸기 전에 버전이 저장됩니다.

## 편집기 설정

왼쪽 레일 아래쪽의 **설정**은 왼쪽에 분류별로 설정을 모아 둡니다.

- **프로젝트**: 컴파일러, 기본 문서, 맞춤법 검사 언어(편집자가 모든 사람을 위해 변경), Git clone 주소.
- **화면 표시**: 글꼴 크기, 글꼴(고정폭 또는 산세리프), 줄 높이, **코드 색상**(GitHub, Solarized, Monokai, Dracula, Nord, One Dark 등. 코드 모드 전용), 이동 경로.
- **편집**: 키 바인딩(기본값, Vim 또는 Emacs)과 코드 검사, 수식 미리 보기, 괄호 자동 닫기, 자동 완성 스위치.
- **키보드 단축키**: 아래를 참고하세요.
- **작업**: 단어 수, 복사, Word로 내보내기, 템플릿 변환, 템플릿으로 게시.

화면 표시, 편집, 단축키는 나만의 설정으로, 이 브라우저에 저장되어 모든 프로젝트에 적용됩니다.

## 키보드 단축키

왼쪽 레일의 **단축키**에 모든 단축키가 나열됩니다. 자주 쓰는 단축키는 다음과 같습니다.

| 작업 | 키 |
| --- | --- |
| 컴파일 | `Mod+S` 또는 `Mod+Enter` |
| 실행 취소 / 다시 실행 | `Mod+Z` / `Mod+Shift+Z` |
| 검색 및 바꾸기 | `Mod+F` |
| 굵게 / 기울임꼴 | `Mod+B` / `Mod+I` |
| 행 주석 처리 또는 해제 | `Mod+/` |
| 행으로 이동 | `Mod+Alt+G` |
| 선택 영역에 댓글 달기 | `Mod+Alt+M` |
| 추천 항목 표시 | `Ctrl+Space` |

키는 사용하는 시스템에 맞게 표시됩니다. Mac에서는 ⌘, ⌥, ⇧, Windows와 Linux에서는 Ctrl, Alt, Shift입니다. 위는 기본 키입니다.

### 나만의 단축키

설정의 **키보드 단축키**에서 명령 옆의 **변경**을 클릭하고 새 키를 누릅니다. Ctrl(Mac에서는 ⌘) 또는 Alt가 필요하며, 다른 명령이 쓰는 키나 브라우저와 기본 편집(실행 취소, 복사, 붙여넣기, 모두 선택 등)에 남겨 둔 키는 쓸 수 없습니다. 하나씩 또는 모두 재설정할 수 있습니다. 그러면 도구 모음의 힌트와 단축키 목록에 내 키가 표시됩니다.
