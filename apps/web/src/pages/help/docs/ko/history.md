# 기록

편집기 상단의 **기록**을 누르면 기록 보기가 열립니다. git log처럼 동작하며, 모든 버전에는 짧은 ID(예: `a1b2c3d`), 설명, 만든 시각과 만든 사람이 표시됩니다.

- 편집을 잠시 멈추면 변경한 사람 정보와 함께 버전이 자동으로 기록됩니다.
- **버전 저장**은 현재 상태를 설명(커밋 메시지와 같은)과 함께 바로 기록합니다. 마지막 버전 이후 바뀐 것이 없으면 설명은 그 버전의 레이블이 됩니다.
- 버전을 선택하면 어떤 파일이 어떻게 바뀌었는지 보거나 현재 프로젝트와 비교할 수 있습니다.
- **이 변경 내용 되돌리기**는 그 버전에서 바뀐 부분만 되돌리고 그 이후의 변경 내용은 모두 유지합니다(`git revert`처럼). 이후에 파일이 충돌하는 방식으로 다시 바뀌었다면 아무것도 바꾸지 않고 해당 파일 이름을 알려 줍니다.
- **프로젝트 복원**은 모든 파일을 그 버전의 상태로 되돌리며, 그 이후 추가된 파일은 제거합니다. **이 파일 복원**은 한 파일만 그렇게 합니다.
- 되돌리기와 복원도 각각 하나의 버전으로 남으므로("a1b2c3d 되돌림", "a1b2c3d(으)로 복원". ID를 클릭하면 해당 버전으로 이동) 이것들도 실행 취소할 수 있습니다.
- **레이블 추가**로 버전에 이름(예: "제출함")을 붙여 두면 나중에 쉽게 찾을 수 있습니다.
- 어떤 버전의 파일이든 .zip으로 다운로드할 수 있습니다.

> AI 변경 내용을 적용하기 전, 프로젝트 전체 바꾸기, git push, 되돌리기, 복원 전에도 버전이 저장됩니다.
