# 협업

## 사람 초대하기

편집기 오른쪽 위의 **공유**를 클릭합니다.

- 프로젝트는 이 서버에 계정이 있는 사람과만 공유할 수 있습니다. 이름이나 이메일의 일부를 입력하고 목록에서 계정을 고른 뒤 역할을 정하고 **+** 버튼을 클릭합니다.
- 계정이 없는 사람은 먼저 관리자나 시스템 관리자에게 초대 링크를 받아야 합니다. [관리](#/help/admin)를 참고하세요.
- 멤버 목록에서 역할을 바꾸거나, 소유권을 이전하거나, 사람을 제거할 수 있습니다. 멤버는 소유자만 관리할 수 있습니다.

### 역할

| 역할 | 할 수 있는 일 |
| --- | --- |
| 소유자 | 멤버 관리, 프로젝트 삭제, 템플릿으로 게시를 포함한 모든 작업 |
| 편집자 | 파일 편집 및 관리, 제안 수락 또는 거부 |
| 검토자 | 추적되는 제안으로만 텍스트 변경, 댓글 달기 |
| 뷰어 | 읽기, 컴파일, 다운로드, 댓글 달기 |

## 함께 편집하기

여러 사람이 같은 파일을 동시에 편집할 수 있습니다. 커서마다 고유한 색이 있고, 상단에 지금 접속한 사람이 표시됩니다. 변경 내용은 실시간으로 동기화되므로 따로 저장할 필요가 없습니다.

## 댓글

텍스트를 선택하고 도구 모음의 댓글 버튼을 클릭합니다(또는 `Mod+Alt+M`). 댓글은 왼쪽의 **검토** 패널에 모이며, 그곳에서 답글을 달고 편집하고 해결할 수 있습니다. `@`를 입력해 다른 사람을 언급하면 그 사람에게 알림이 갑니다.

## 변경 내용 추적

검토 패널에서 모든 사용자 또는 일부 사람에 대해 변경 내용 추적을 켭니다. 그러면 편집 내용이 제안이 됩니다.

- 삭제한 텍스트에는 취소선이, 새 텍스트에는 강조 표시가 됩니다.
- 편집자는 제안을 하나씩 또는 한꺼번에 **수락**하거나 **거부**합니다. 실수로 내린 결정은 이어서 나타나는 메시지의 **실행 취소**로 되돌릴 수 있습니다(15분 동안).
- 검토자의 편집은 항상 추적되며, 검토자는 패널에서 자신의 제안을 **철회**할 수 있습니다.
- 내 실수는 `Ctrl/Cmd+Z`로 추적된 편집을 실행 취소할 수 있고, 삭제한 텍스트를 원래 자리에 다시 입력하면 새 제안이 생기는 대신 삭제가 복원됩니다.
- PDF에는 제안이 반영된 텍스트가 표시됩니다.

## 채팅

왼쪽 레일의 **채팅**은 프로젝트 채팅입니다.

- `Enter`로 보내고, `Shift+Enter`로 줄을 바꿉니다.
- `@`로 멤버를 언급합니다.
- `$…$` 안의 수식은 조판되어 표시됩니다(예: `$x^2$`).

## 알림

채팅이나 댓글에서의 언급, 내 댓글에 달린 답글, 프로젝트에 추가된 일은 **알림**에 표시되며, 사이드바에 읽지 않은 개수가 나옵니다. 알림은 ColTex 안에서만 오며 이메일은 보내지 않습니다.
