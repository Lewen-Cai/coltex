# 템플릿

## 템플릿으로 새 프로젝트 만들기

새 프로젝트는 기본 제공 템플릿이나 이 서버에서 공유된 템플릿으로 시작할 수 있습니다. [시작하기](#/help/getting-started)를 참고하세요.

## 프로젝트를 템플릿으로 게시하기

프로젝트 소유자는 프로젝트를 이 서버의 모든 사람이 쓸 수 있는 템플릿으로 게시할 수 있습니다. 예를 들어 연구실의 학위 논문 양식처럼 말입니다.

1. 프로젝트 목록의 프로젝트 메뉴(⋯) 또는 프로젝트 설정에서 **템플릿으로 게시…** 메뉴를 선택합니다.
2. 이름과 설명을 입력하고 **게시**를 클릭합니다.

알아 두면 좋은 점:

- 이 템플릿으로 만든 새 프로젝트에는 **그 시점**의 프로젝트 파일, 컴파일러, 맞춤법 검사 언어가 들어갑니다. 멤버, 기록, 댓글은 포함되지 않습니다.
- 템플릿은 프로젝트를 따라갑니다. 프로젝트를 바꾸면 이후에 만드는 새 프로젝트에 그 변경 내용이 반영됩니다.
- **템플릿으로 게시…** 메뉴를 다시 열면 이름을 바꾸거나 **게시 취소**할 수 있습니다. 관리자는 새 프로젝트 대화 상자에서 공유 템플릿을 제거할 수도 있습니다.
- 프로젝트를 삭제하면 템플릿도 사라집니다.

## 저널 템플릿으로 변환하기

프로젝트 메뉴의 **템플릿으로 변환…**(프로젝트 설정에서는 "저널 템플릿으로 변환")은 논문을 다른 저널이나 학회 양식으로 다시 작성합니다. IEEE Transactions, IEEE Conference, ACM Conference, ACM Journal, Elsevier, Springer LNCS, APS(REVTeX) 또는 기본 article을 지원합니다.

- 제목, 저자, 소속, 초록, 패키지, 참고문헌이 **새 프로젝트**에 다시 구성된 뒤 컴파일됩니다. 원본은 그대로 유지됩니다.
- 보고서에 무엇이 바뀌었고 무엇을 확인해야 하는지 나옵니다. 남은 문제는 AI가 처리할 수 있습니다.
