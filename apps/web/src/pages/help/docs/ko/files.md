# 파일

## 파일 트리

- 상단의 버튼: 새 파일, 새 폴더, 업로드, 연결된 파일 추가.
- 파일을 폴더로 끌어다 놓으면 이동하고, 이름을 더블클릭하면 이름을 바꿉니다. 컴퓨터에서 끌어다 놓은 파일은 업로드됩니다.
- 파일이나 폴더를 마우스 오른쪽 버튼으로 클릭하면 만들기, 업로드, 이름 바꾸기, 삭제를 할 수 있습니다.
- 파일 옆의 색깔 점은 다른 사람이 그 파일을 열어 두었다는 뜻입니다.

삭제한 파일은 기록에서 되살릴 수 있습니다.

## 연결된 파일

연결된 파일은 다른 곳에서 가져온 파일로, 언제든지 원본에서 새로 고칠 수 있습니다.

- **다른 프로젝트에서**: 다른 프로젝트의 아무 파일이나, 그 프로젝트의 컴파일된 PDF(먼저 빌드됨). 공용 그림이나 공용 `.bib`를 쓰거나, 한 프로젝트의 PDF를 다른 프로젝트의 그림으로 쓸 때 유용합니다.
- **URL에서**: 공개 주소에서 다운로드합니다(최대 50 MB). 로컬 네트워크나 사설 네트워크의 주소는 사용할 수 없습니다.

> 연결된 파일은 트리에 링크 표시가 붙으며, 마우스를 올리면 출처가 보입니다. 마우스 오른쪽 버튼을 클릭하고 **연결된 파일 새로 고침**을 선택하면 다시 가져와 바꿉니다. 추가하거나 새로 고치려면 내가 원본 프로젝트에 접근할 수 있어야 합니다.

## Git

모든 프로젝트는 git으로 clone, pull, push할 수 있습니다.

1. **설정 → 동기화 서비스**에서 Git용 토큰을 만듭니다(한 번만 표시되니 보관해 두세요). **읽기 전용** 토큰으로는 clone과 pull은 되지만 push는 할 수 없습니다.
2. 프로젝트 설정에서 clone 주소를 복사해 `git clone <address>`를 실행합니다. git이 물으면 사용자 이름은 아무것이나, 비밀번호에는 토큰을 입력합니다.
3. 로컬에서 커밋하고 `git push`하면 변경 내용이 바로 프로젝트에 반영되어 공동 작업자에게 보입니다.

알아 두면 좋은 점:

- 각 프로젝트에는 `main` 브랜치 하나만 있습니다.
- 마지막 pull 이후 누군가 프로젝트를 바꿨다면 git이 push를 거부합니다. 먼저 `git pull`한 뒤 다시 push하세요.
- push가 적용되기 전에 프로젝트 상태가 버전으로 저장됩니다.
- 검토자와 뷰어는 push할 수 없습니다.
- 토큰을 매번 입력하지 않으려면 `git config --global credential.helper store`(Mac에서는 `osxkeychain`)를 사용하세요.
