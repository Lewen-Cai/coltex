# 설정

왼쪽 아래의 아바타를 클릭하고 **설정**을 선택합니다.

- **계정**: 표시 이름(공동 작업자, 댓글, 기록에 표시됨), 아바타 색상(편집기의 내 커서 색상이기도 합니다. **자동**은 ColTex가 고른 색상입니다), 비밀번호입니다. 비밀번호를 바꿀 때 다른 기기에서 로그아웃할 수 있습니다. 비밀번호는 대문자, 소문자, 숫자를 포함해 8자 이상이어야 하며 기호는 선택 사항입니다. 입력하는 동안 표시되는 강도(약함, 보통, 좋음, 강함)는 길이가 길고 기호가 있을수록 올라갑니다. 가입과 관리자의 재설정에도 같은 규칙이 적용됩니다. 로그인 이메일은 관리자만 바꿀 수 있습니다. 2단계 인증과 로그인 기록도 이 페이지에 있습니다(아래 참고).
- **화면 표시**: 테마(파란색의 라이트와 다크, 초록색의 포레스트와 모스, 보라색의 라벤더와 플럼. 기본값은 라이트)와 인터페이스 언어(English, 简体中文, 繁體中文, 日本語, 한국어, Español, Français, Deutsch 등 14개 언어. 처음에는 브라우저 언어로 시작합니다)를 정합니다. 다크 테마는 편집기에도 적용되며, PDF 페이지는 흰색으로 유지됩니다. 테마는 계정에 저장되므로 다른 브라우저에서도 그대로 적용되며(로그인 페이지는 항상 라이트), 언어는 이 브라우저에 저장됩니다.
- **동기화 서비스**: Zotero 계정을 연결하고([참고문헌](#/help/references) 참고), git 토큰을 만들고 취소합니다([파일](#/help/files) 참고). 토큰마다 Git, MCP 또는 둘 다, 읽기 및 쓰기 또는 읽기 전용, 모든 프로젝트 또는 일부 프로젝트, 만료일을 정합니다. 컴퓨터마다 토큰을 하나씩 쓰면 따로따로 취소할 수 있습니다.
- **AI 에이전트**: 최근 7일, 30일 또는 90일 동안의 AI 사용량(요청, 토큰, 비용, 일별 및 모델별)과 남은 한도(AI 에이전트를 사용할 수 있는 경우), AI 에이전트가 나 대신 바꿀 수 있는 범위(**권한**), 그리고 토큰을 사용해 **MCP**로 내 AI 에이전트를 연결하는 방법이 있습니다. [AI 에이전트](#/help/ai)를 참고하세요.
- **AI Skill**(AI 에이전트를 사용할 수 있는 경우): 내 Skill, 기본 제공 Skill, 그리고 Skill 작성을 위한 AI 에이전트와의 대화가 있습니다. [AI 에이전트](#/help/ai)를 참고하세요.

## 2단계 인증

2단계 인증을 켜면 로그인할 때 비밀번호 다음에 휴대폰 인증 앱(Google Authenticator, Microsoft Authenticator, 1Password, Bitwarden 등)의 코드를 묻습니다. 켤지는 본인이 정하며, 다른 사람이 대신 켤 수는 없습니다.

1. **설정 → 계정**의 **2단계 인증**에서 **켜기**를 클릭하고 비밀번호를 입력합니다.
2. 앱으로 QR 코드를 스캔하고(또는 설정 키를 앱에 직접 입력하고), 앱에 표시된 6자리 코드를 입력합니다.
3. 10개의 **복구 코드**를 저장합니다(복사하거나 파일로 다운로드). 휴대폰을 잃어버렸을 때 각 코드로 인증 코드 대신 한 번씩 로그인할 수 있습니다. 복구 코드는 지금만 표시됩니다.

로그인할 때 비밀번호 다음에 앱의 코드를 입력하거나 **복구 코드 사용**을 클릭합니다. **이 기기에서 30일 동안 다시 묻지 않기**를 선택하면 그 브라우저에서는 코드를 묻지 않습니다. **새 복구 코드**는 이전 코드를 대체하며(새 코드를 보관하세요), **끄기**는 비밀번호만 쓰는 방식으로 되돌립니다. Git 및 MCP 토큰은 이전처럼 작동합니다.

> 휴대폰과 복구 코드를 모두 잃어버렸나요? 시스템 관리자가 서버에서 내 계정의 2단계 인증을 끌 수 있습니다(`coltex reset-2fa <email>`). 그다음 비밀번호로 로그인하고 다시 켤 수 있습니다.

## 로그인 기록

**설정 → 계정** 아래쪽의 **로그인 기록**에는 내 계정의 로그인이 최신순으로 나열됩니다. 시각, 결과(로그인함, 잘못된 비밀번호, 잘못된 코드, 거부됨), 브라우저와 시스템, 주소와 그 위치(로컬 네트워크, Tailscale, 또는 인터넷 주소라면 국가, 지역, 도시, 통신사)가 표시됩니다. 위치는 서버의 데이터베이스에서 찾으며, 주소를 조회하려고 다른 곳으로 보내지 않습니다. 기록은 90일 동안 보관됩니다.

편집기 설정(글꼴 크기, 색상, Vim 등)은 편집기 왼쪽 레일 아래쪽의 **설정**에 있습니다. [편집기](#/help/editor)를 참고하세요.
