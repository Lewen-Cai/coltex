# 시작하기

ColTex는 내 서버에서 실행되는 협업 LaTeX 편집기입니다. Overleaf와 거의 같은 방식으로 동작합니다. 왼쪽에 소스, 오른쪽에 PDF가 있고, 여러 사람이 같은 프로젝트를 동시에 편집할 수 있습니다.

## 새 프로젝트

왼쪽 위의 **새 프로젝트**를 클릭하고, 이름을 입력한 뒤 템플릿을 고릅니다.

| 템플릿 | 클래스 |
| --- | --- |
| 빈 article | 표준 `article`, 가장 간단한 시작 |
| arXiv 프리프린트 | `article`, 1단, 소속이 포함된 저자(authblk), natbib 참고문헌 |
| IEEE 학회 / IEEE 저널 | 학회 / 저널 모드의 `IEEEtran` |
| ACM 학회 / ACM 저널 | `acmart` sigconf / acmsmall |
| Springer LNCS | `llncs`, LNCS 및 기타 Springer 논문집용 |
| Elsevier 저널 | `elsarticle`, 1단 프리프린트 |
| APS (REVTeX 4.2) | `revtex4-2`, Physical Review 및 AIP 저널용 |

빈 article을 제외한 각 템플릿에는 초록, 키워드, 수식, 그림, 표, `references.bib`가 들어 있으며 그대로 빌드됩니다. 클래스는 TeX Live에 포함된 공식 클래스입니다. 해마다 새 스타일 파일을 내는 학회(NeurIPS, ICML)는 TeX Live에 없습니다. 그해의 파일을 프로젝트에 업로드하고 템플릿으로 게시하세요.

사람들이 템플릿으로 게시한 프로젝트(예: 연구실의 학위 논문 양식)는 "이 서버에서 공유됨"에 나옵니다.

새 프로젝트는 **자동**으로 컴파일됩니다. 빌드할 때마다 문서를 보고 엔진을 고릅니다. [컴파일과 PDF](#/help/compiling)를 참고하세요.

Overleaf에서 프로젝트를 옮겨 오려면 Overleaf에서 **Download Source**를 선택하고, 받은 zip을 여기서 **가져오기**합니다(최대 200 MB). 기본 문서는 자동으로 감지되며, 컴파일러도 자동으로 설정됩니다.

## 편집기

- **위쪽**: 프로젝트 이름, 접속한 사람, **기록**, **공유**.
- **왼쪽 레일**: 왼쪽 패널을 파일, 검색, 참고문헌, 검토, 채팅, AI 사이에서 전환합니다. 키보드 단축키와 프로젝트 설정은 레일 아래쪽에 있습니다.
- **가운데**: 편집기. 도구 모음에 **코드 / 비주얼**이 있습니다.
- **오른쪽**: PDF. **다시 컴파일**, **로그**, PDF에서 위치 보기 버튼, 새 창에서 열기, 다운로드가 있습니다.

## 컴파일과 PDF

- **다시 컴파일**을 클릭하거나 `Mod+S` / `Mod+Enter`를 누릅니다. 자동 컴파일이 기본으로 켜져 있어 입력을 잠시 멈추면 빌드합니다.
- **로그**에는 오류 개수가 표시됩니다. 열면 각 오류와 설명을 볼 수 있고, 오류를 클릭하면 해당 행으로 이동합니다. 오류는 편집기의 줄 번호 옆에도 표시됩니다.
- **소스 ↔ PDF**: 커서를 소스에 둔 채 PDF 막대의 조준선 버튼을 클릭하면 PDF가 그 위치로 스크롤됩니다. PDF를 더블클릭하면 소스로 돌아갑니다.
- **별도 창의 PDF**: PDF 막대의 "새 창에서 PDF 열기"를 사용하면 편집기가 창 전체를 차지하는 동안 PDF를 다른 화면에 둘 수 있습니다. [컴파일과 PDF](#/help/compiling)를 참고하세요.
