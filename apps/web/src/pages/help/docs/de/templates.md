# Vorlagen

## Neue Projekte aus Vorlagen

Neue Projekte können mit einer integrierten Vorlage oder einer auf diesem Server geteilten beginnen; siehe [Erste Schritte](#/help/getting-started).

## Ein Projekt als Vorlage veröffentlichen

Der Eigentümer eines Projekts kann es als Vorlage für alle auf diesem Server veröffentlichen, etwa für das Dissertationsformat einer Arbeitsgruppe:

1. Wählen Sie im Menü des Projekts (⋯) in der Projektliste oder in den Projekteinstellungen **Als Vorlage veröffentlichen…**.
2. Geben Sie einen Namen und eine Beschreibung ein und klicken Sie auf **Veröffentlichen**.

Gut zu wissen:

- Neue Projekte daraus erhalten die Dateien des Projekts so, wie sie **zu diesem Zeitpunkt** sind, seinen Compiler und seine Sprache für die Rechtschreibprüfung; nicht aber seine Mitglieder, seinen Verlauf oder seine Kommentare.
- Die Vorlage folgt dem Projekt: Ändern Sie das Projekt, erhalten später erstellte Projekte die Änderungen.
- Öffnen Sie **Als Vorlage veröffentlichen…** erneut, um sie umzubenennen oder **Zurückziehen** zu wählen. Administratoren können geteilte Vorlagen auch im Dialog für neue Projekte entfernen.
- Sie verschwindet, wenn das Projekt gelöscht wird.

## In eine Zeitschriftenvorlage umwandeln

**In Vorlage umwandeln…** im Menü eines Projekts (in den Projekteinstellungen: „In eine Zeitschriftenvorlage umwandeln“) schreibt ein Paper für eine andere Zeitschrift oder Konferenz um: IEEE Transactions, IEEE-Konferenz, ACM-Konferenz, ACM-Zeitschrift, Elsevier, Springer LNCS, APS (REVTeX) oder einen einfachen Artikel.

- Titel, Autoren, Affiliationen, Abstract, Pakete und Literaturverzeichnis werden in einem **neuen Projekt** neu aufgebaut, das anschließend kompiliert wird. Das Original bleibt unverändert.
- Ein Bericht listet auf, was geändert wurde und was zu prüfen ist. Den Rest kann die KI erledigen.
