# Templat

## Proyek baru dari templat

Proyek baru dapat dimulai dari templat bawaan atau templat yang dibagikan di server ini; lihat [Memulai](#/help/getting-started).

## Menerbitkan proyek sebagai templat

Pemilik proyek dapat menerbitkannya sebagai templat untuk semua orang di server ini, misalnya untuk format tesis sebuah kelompok:

1. Di menu proyek (⋯) pada daftar proyek, atau di pengaturan proyek, pilih **Terbitkan sebagai templat…**.
2. Beri nama dan deskripsi, lalu klik **Terbitkan**.

Perlu diketahui:

- Proyek baru dari templat ini mendapat file proyek seperti adanya **pada saat itu**, kompilatornya, dan bahasa pemeriksaan ejaannya; tidak termasuk anggota, riwayat, atau komentarnya.
- Templat mengikuti proyeknya: ubah proyeknya, dan proyek baru yang dibuat kemudian akan mendapat perubahan itu.
- Buka **Terbitkan sebagai templat…** lagi untuk mengganti namanya atau memilih **Batalkan penerbitan**. Administrator juga dapat menghapus templat bersama di dialog proyek baru.
- Templat hilang ketika proyeknya dihapus.

## Mengonversi ke templat jurnal

**Konversi ke templat…** di menu proyek (di pengaturan proyek: "Konversi ke templat jurnal") menulis ulang makalah untuk jurnal atau konferensi lain: IEEE Transactions, IEEE Conference, ACM Conference, ACM Journal, Elsevier, Springer LNCS, APS (REVTeX), atau artikel polos.

- Judul, penulis, afiliasi, abstrak, paket, dan bibliografi dibangun ulang dalam **proyek baru**, yang kemudian dikompilasi. Proyek asli tetap seperti semula.
- Sebuah laporan mencantumkan apa yang diubah dan apa yang perlu diperiksa. AI dapat menangani sisanya.
