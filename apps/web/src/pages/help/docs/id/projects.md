# Proyek

## Daftar proyek

- **Ruang kerja**: setiap proyek yang Anda miliki atau yang Anda ikuti sebagai anggota; cari, beralih antara daftar dan kartu, saring berdasarkan pemilik.
- **Dibagikan dengan saya**: proyek yang orang lain undang Anda ke dalamnya.

Menu proyek (⋯) berisi: buka, ganti nama (pemilik dan editor), buat salinan, unduh .zip, unduh PDF, konversi ke templat, terbitkan sebagai templat (pemilik), arsipkan, dan pindahkan ke sampah. Pilih beberapa proyek di daftar untuk menindaklanjutinya sekaligus.

## Mengganti nama

Pemilik dan editor mengganti nama proyek dengan **Ganti nama…** di menunya, atau dengan mengklik namanya di bagian atas editor: Enter menyimpan, Esc membatalkan. Semua orang langsung melihat nama baru, juga di editor yang sedang terbuka.

## Tag

**Tag** di bilah sisi mengelompokkan proyek Anda; klik salah satunya untuk melihat hanya proyek dengan tag itu. Tag hanya milik Anda dan tidak pernah mengubah apa yang dilihat anggota lain. Klik tag sebuah proyek (kolom Tag di daftar, atau di kartunya; jika belum ada, **+ Tag** muncul saat kursor diarahkan) untuk mencentang tag atau membuat tag baru, atau pilih beberapa proyek di daftar.

## Arsip dan sampah

- **Arsipkan** mengeluarkan proyek yang sudah selesai dari daftar Anda tanpa mengubahnya; Anda dapat mengeluarkannya dari arsip kapan saja.
- Proyek di **Sampah** dapat dipulihkan. Dari sampah, pemilik dapat memilih **Hapus selamanya** (untuk semua orang); anggota lain memilih **Keluar dari proyek**.

> Arsip dan sampah hanya mengubah daftar Anda sendiri, sampai pemilik menghapus proyek secara permanen.

## Salinan

**Buat salinan** membuat proyek baru milik Anda dengan semua file dan pengaturannya, tetapi tanpa kolaborator, riwayat, atau komentar. Pelihat juga dapat membuat salinan.
