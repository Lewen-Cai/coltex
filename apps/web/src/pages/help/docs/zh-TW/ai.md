# AI 代理

左側欄的 **AI** 會開啟 AI 代理。管理員連接模型服務並將你加入 AI 群組後就可以使用；群組決定你可以使用哪些模型。

## 它能做什麼

- 回答 LaTeX 問題，解釋選取的程式碼。
- 解釋或修正編譯錯誤（記錄檔中也有「用 AI 修正」按鈕）。
- 改寫、潤飾或翻譯選取的內容。
- 概述專案、找出沒有被參照的標籤等。
- 查看 PDF 頁面檢查排版，例如圖表是否放進欄中、方程式是否超出（需要能看圖的模型）。

目前開啟的檔案、選取的內容和最近的編譯錯誤會附加在你的訊息中；按一下附件即可將它排除。

## 權限

AI 代理可以修改什麼由你決定：在 **設定 → AI 代理** 中，或在面板底部的模型選擇器中（思考程度下方）選擇；訊息輸入框下方的那一行會顯示目前的設定。同樣的選擇也適用於你透過 MCP 連接的代理（見下文）。

- **手動**（預設）：AI 代理的修改會放進草稿，在你套用之前不會有任何變更。
  1. 完成後，草稿會先試編譯，並告訴你它是否會增加錯誤。
  2. **審閱修改** 會依檔案顯示差異；你可以只套用其中一部分。
  3. **套用** 會把修改寫入專案並編譯；如果編譯結果變差，就會復原。套用前會先儲存一個版本。
  4. 套用後，**復原** 可以撤銷這些修改，同時保留其他人在這段期間所做的編輯。
- **自動**：AI 代理一完成回答就套用草稿，並有相同的保護機制：先儲存版本、編譯專案、編譯結果變差就復原，之後也可以按 **復原**。如果在這段期間有人修改了相同的行，則不會套用，草稿會等你處理。你停止 AI 代理時，它的草稿也會等你處理。
- **完整存取**：在自動的基礎上，AI 代理還可以刪除、移動和重新命名檔案。這些操作會立即執行，不會放進草稿；每次回答中的第一個此類操作之前會先儲存一個版本。回答中會列出這些操作和它修改的檔案。

檢視者和審閱者可以向 AI 代理提問，但它無法替他們修改任何內容。

## 網路

設定好網路搜尋後，AI 代理就可以搜尋網路和讀取網頁，例如期刊最新的投稿要求、套件的更新說明，或核對某個說法的出處。Anthropic、OpenAI 和 ChatGPT 的模型使用它們內建的網路搜尋，其他模型使用管理員連接的搜尋服務。它搜尋了什麼、讀了哪些網頁，都會以步驟顯示在對話中，回答時也會說明依據哪些網頁。

為了不讓專案內容藉此外流：
- 搜尋字詞只會送到管理員選定的搜尋服務（或模型內建的搜尋），最長 128 個字元。
- 只能讀取你在對話中寫過的網址，或搜尋結果提供的網址，而且必須一字不差；它無法自行編造網址。
- 只讀不送：不會上傳或送出任何內容。

網頁任何人都能撰寫，可能藏有誤導 AI 代理的指令。因此只要你能連網，即使權限是 **自動** 或 **完整存取**，AI 代理的修改也都會等你審閱後才套用，並且不會刪除或移動檔案。你的 AI 工具（MCP）仍依你的權限執行。

## 模型與思考

- 在面板底部選擇模型。選擇 **自動** 時，ColTex 會依問題選用輕量或強力模型。
- 對於會思考的模型，思考程度在同一個選擇器中設定；訊息輸入框下方的那一行會顯示它。

## 對話與上下文

- 對話會依專案為你保存（其他人永遠看不到）。**新對話** 會開始另一段對話；**歷史對話** 會列出先前的對話：可以開啟、重新命名或刪除。重新開啟一段對話會從中斷的地方繼續；未套用的草稿不會保留，所以要離開有草稿的對話時會先詢問你。
- 訊息輸入框下方的圓環顯示這段對話用了模型上下文視窗的多少（例如 `12k / 200k`）。達到 70% 時會變成琥珀色，達到 90% 時變成紅色。
- 如果你的 AI 群組設有用量上限，旁邊會有一條長條顯示你在這一天、這一週或這個月的用量（滑鼠移過去可看詳細資訊）。達到上限後，訊息要等到下一個週期才能送出。**設定 → AI 代理** 會顯示你最近 30 天的用量和剩餘額度。
- 在訊息輸入框中輸入 `/` 可以使用指令：
  - `/compact`：摘要目前為止的對話，並從摘要繼續，以釋放上下文。訊息仍然可以看到；AI 代理會透過摘要記住它們。
  - `/new`：開始新對話。
  - `/chats`：先前的對話。
- 輸入框會隨輸入的內容變高。拖曳它的上邊緣可以調高（在這個瀏覽器中會記住，專案聊天也一樣）；按兩下上邊緣即可恢復。

## Skill

Skill 是一組指示，用於你一再重複的工作，例如「把摘要縮短到期刊的字數限制」或「檢查每張圖是否都被參照」。Skill 使用 Agent Skills 格式（一個包含名稱、說明和指示的 `SKILL.md`），因此為其他 AI 代理撰寫的 Skill 在這裡也能使用。

- **你的 Skill** 位於 **設定 → AI Skill**；只有你看得到，而且可以在每個專案中使用。
- 已有的 Skill 用 **匯入** 加入：**上傳檔案** 接受一個 `SKILL.md` 及其參考檔案，或一個包含 Skill 資料夾的 `.zip`；**上傳資料夾** 接受一個 Skill 的資料夾，或包含多個 Skill 的資料夾。Skill 中的指令碼會保存為 AI 代理可以閱讀的文字；Skill 中的任何內容都不會被執行。
- 要使用 Skill，請輸入 `/` 並選擇它，再加上你的訊息（`/polish-abstract keep it under 200 words`）。AI 代理也會閱讀 Skill 的說明，當你的要求符合某個 Skill 時會自行載入。
- 請 AI 代理把某件事做成 Skill（「把我們剛才修正參考文獻的方法存成 Skill」）：它會在對話中起草一個，你可以編輯它，或將它存到你的 Skill 中。
- 在 **設定 → AI Skill** 中，你的 Skill 列在左側；選擇一個即可閱讀其指示和參考檔案，或按 **用 AI 建立** 開啟與 AI 代理一起撰寫 Skill 的對話（在你的某個 Skill 上按 **在對話中改進**，會開始一則關於它的訊息）。這個對話遵循內建的 **skill-creator** Skill：它會詢問你打算如何使用這個 Skill、起草 Skill（有幫助時也會附上參考檔案），還可以在你貼上的文字上試用草稿。草稿只有在你儲存時才會保存；以已經使用中的名稱儲存時，會先詢問是否取代。對話會一直保留，直到你開始新的對話。
- ColTex 附有內建 Skill（列在 **內建** 之下）。你可以閱讀和下載，但不能修改；如果你自己有同名的 Skill，則會改用你的 Skill。
  - **skill-creator**：撰寫 Skill（Skill 對話遵循它）。
  - **template-conversion**：完成範本轉換：先問你要投的期刊或會議，查詢其投稿要求，再依要求調整論文（轉換後按 **開啟並用 AI 修正** 就會使用它）。

## 你自己的 AI 工具（MCP）

Claude Code、Codex、Cursor、VS Code（Copilot）、Windsurf、Gemini CLI、Cline 或 OpenCode 等 AI 工具可以直接處理你的專案：列出專案、閱讀和搜尋檔案、編輯檔案、編譯並讀取記錄檔、查看版本記錄，以及閱讀、新增和回覆註解。ColTex 是它們的 MCP 伺服器，你所有的專案共用同一個位址；工具會指明它要處理哪個專案。

在 **設定 → AI 代理** 的 **連接你的 AI 工具（MCP）** 中，在左側選擇你的工具，然後依照三個步驟操作：位址、權杖（**建立權杖**；只會顯示一次），以及已填好這兩項、可直接複製的設定。任何其他透過 HTTP 連接 MCP 伺服器、並以標頭傳送權杖的工具也都可以使用（**其他**）。只接受透過 OAuth 登入之伺服器的應用程式（例如 Claude 或 ChatGPT 的自訂連接器）目前還無法連接。

你的工具可以修改什麼，取決於你在 **設定 → AI 代理** 中的權限：

- **手動**（預設）：它們的編輯會成為你的修改建議，由你和協作者在 **審閱** 中接受或拒絕。新檔案會直接建立。
- **自動**：它們的編輯會直接套用，就像你自己的編輯一樣。如果你開啟了追蹤修訂，這些編輯仍會是修改建議。
- **完整存取**：在自動的基礎上，它們還可以刪除、移動和重新命名檔案。

工具隔了一段時間後第一次修改之前，專案的狀態會先儲存為一個版本，讓你可以回到之前的狀態。審閱者的工具只能提出修改建議，檢視者的工具只能閱讀和加入註解。

### 安全性

- 任何持有你權杖的人都能以你的身分操作：請像保管密碼一樣保管它，不再需要時在權杖清單中撤銷它（每個工具或每台電腦使用一個權杖，就很容易做到）。建立權杖時，只給它需要的權限：
  - **用途**：Git、MCP 或兩者。只為 MCP 建立的權杖不能 clone 或 push，反之亦然。
  - **存取權限**：**唯讀** 讓工具可以列出、閱讀、搜尋和編譯，但不能修改檔案或註解（git 則可以 clone 和 pull，但不能 push），不論你的權限為何。
  - **專案**：你的所有專案，或只限你選取的專案；對這個權杖來說，其他專案並不存在。
  - **有效期限**：30 天、90 天、一年或永不到期。到期的權杖會停止運作；請撤銷它並建立新的權杖。
- ColTex 只回應你的工具；它從不連接其他 MCP 伺服器。你的工具還能做什麼（透過 Playwright MCP 操作瀏覽器、終端機、其他服務）取決於工具本身及其設定。專案的文字、註解和記錄檔可能是協作者寫的，因此讀取它們的工具，可能會被這些文字要求使用它的其他能力去做某些事。ColTex 會告訴工具把專案內容當成內容而不是指示，但只有你的工具能真正落實這一點：對於 ColTex 以外的操作，請保持工具本身的確認機制開啟；工具同時能操作瀏覽器或終端機時，請使用 **手動**。
- 能操作瀏覽器、且該瀏覽器已登入 ColTex 的工具，會透過網頁以你的完整權限操作，而不是透過 MCP，因此上述權限在那裡無法限制它。請讓這類工具使用未登入的瀏覽器設定檔。
