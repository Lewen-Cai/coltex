# 專案

## 專案清單

- **工作區**：你擁有或身為成員的所有專案；可以搜尋、在清單與卡片之間切換、依擁有者篩選。
- **與我共用**：其他人邀請你加入的專案。

專案選單（⋯）中有：開啟、建立副本、下載 .zip、下載 PDF、轉換為範本、發佈為範本（擁有者）、封存和移至垃圾桶。在清單中選取多個專案，即可一次對它們進行操作。

## 標籤

側邊欄的 **標籤** 用來整理你的專案；按一下某個標籤，就只會顯示帶有該標籤的專案。標籤只屬於你自己，不會改變其他成員看到的內容。按一下專案的標籤（清單中的「標籤」欄，或卡片上；沒有標籤時，滑鼠移過去會出現 **+ 標籤**）即可勾選標籤或建立新標籤，也可以在清單中選取多個專案。

## 封存與垃圾桶

- **封存** 會把已完成的專案移出你的清單，但不會修改它們；隨時都可以取消封存。
- **垃圾桶** 中的專案可以還原。在垃圾桶中，擁有者可以 **永久刪除**（對所有人）；其他成員則是 **退出專案**。

> 封存和垃圾桶只會改變你自己的清單，直到擁有者永久刪除專案為止。

## 副本

**建立副本** 會建立一個屬於你的新專案，包含所有檔案和設定，但不包括協作者、版本記錄和註解。檢視者也可以建立副本。
