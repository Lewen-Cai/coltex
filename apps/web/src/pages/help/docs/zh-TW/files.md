# 檔案

## 檔案樹

- 標題列上的按鈕：新增檔案、新增資料夾、上傳，以及新增連結檔案。
- 把檔案拖曳到資料夾上即可移動；按兩下名稱即可重新命名。從電腦拖放進來的檔案會被上傳。
- 在檔案或資料夾上按右鍵，可以建立、上傳、重新命名或刪除。
- 檔案旁的彩色圓點表示有其他人正開啟著它。

已刪除的檔案可以從版本記錄中找回。

## 連結檔案

連結檔案來自其他地方，隨時都可以從來源重新整理：

- **來自其他專案**：其他專案中的任何檔案，或它編譯出的 PDF（會先編譯）。適合共用的圖片或共用的 `.bib`，也可以把一個專案的 PDF 當成另一個專案中的圖片。
- **來自網址**：從公開網址下載（最大 50 MB）。不能使用本機或私人網路上的位址。

> 連結檔案在檔案樹中帶有連結標記，滑鼠移過去可以看到來源。按右鍵選擇 **重新整理連結檔案** 會重新取得並取代它。新增或重新整理時，你自己必須有來源專案的存取權限。

## Git

每個專案都可以用 git 進行 clone、pull 和 push：

1. 在 **設定 → 同步服務** 中建立一個用於 Git 的權杖（只會顯示一次，請妥善保存）。**唯讀** 權杖可以 clone 和 pull，但不能 push。
2. 從專案設定中複製 clone 位址，執行 `git clone <address>`。git 詢問時，使用者名稱可任意填寫，密碼請填權杖。
3. 在本機 commit 後執行 `git push`：變更會立即寫入專案，協作者也會馬上看到。

注意事項：

- 每個專案只有一個分支 `main`。
- 如果在你上次 pull 之後有人修改了專案，git 會拒絕 push：請先 `git pull`，再重新 push。
- 套用 push 之前，專案目前的狀態會先儲存為一個版本。
- 審閱者和檢視者不能 push。
- 不想每次都輸入權杖：`git config --global credential.helper store`（Mac 上可用 `osxkeychain`）。
