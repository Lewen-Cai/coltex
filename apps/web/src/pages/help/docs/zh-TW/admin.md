# 管理

系統管理員可以在頭像選單的 **設定** 中看到各個管理頁面；管理員則會在那裡看到 **管理使用者** 和 **邀請**，用於管理自己的團隊。

## 使用者與邀請

- 沒有公開註冊：帳號只能透過邀請連結建立，專案也只能與有帳號的人共用。
- 帳號有三種角色：
  - **成員**。
  - **管理員**：帶領一個 **團隊**，例如指導教授和他的學生。管理員邀請的成員會加入該管理員的團隊，管理員也只能管理這些成員。
  - **系統管理員**：只有一位，就是初次設定時建立的帳號。它負責整個執行個體（AI 服務、備份、網路），可以看到所有人。任何人都無法被設為第二位系統管理員，因此單一管理員帳號無法接管整個執行個體。
- **邀請**：一次性的連結，可以指定一個電子郵件，或（電子郵件留空時）給任何持有連結的人，並設有有效期限。待接受的邀請會在清單中保留其連結（**連結**），ColTex 的每個可連線位址（區域網路、Tailscale、Cloudflare）各有一條。系統管理員可以邀請成員或管理員，並為新帳號選擇 **AI 群組**。管理員只能邀請成員加入自己的團隊；這些成員會取得該管理員的 AI 群組。管理員只能看到和撤銷自己發出的邀請。
- **管理使用者**：系統管理員可以看到所有帳號，將人設為成員或管理員、在團隊之間移動成員（該列選單中的 **團隊**）、重設密碼、開啟 **登入紀錄與裝置**，以及停權或刪除帳號。清單中會標示 **已鎖定** 的帳號，以及開啟了 **兩步驟驗證** 的帳號。管理員可以看到自己和自己的團隊，並且只能為自己團隊的成員重設密碼、停權或刪除帳號。刪除帳號時，該帳號擁有的專案也會被刪除。
- 要把系統管理員角色轉交給其他人（或在該帳號遺失時取回），請在伺服器上執行 `coltex cli system-admin <email>`；原本的系統管理員會變成管理員。
- 忘記密碼了，包括系統管理員的密碼？請在伺服器上執行 `coltex cli reset-password <email>`：它會要求輸入兩次新密碼，並將該帳號在所有地方登出。該帳號的擁有者會收到一則通知，伺服器的記錄檔（`coltex logs`）也會記下這件事。
- 用於兩步驟驗證的手機和復原碼都遺失了？`coltex reset-2fa <email>` 會為該帳號關閉兩步驟驗證（並通知帳號擁有者，同時在伺服器的記錄檔中留下一行紀錄）。

## 登入紀錄

只有系統管理員能看到 **登入紀錄**：這個執行個體的每一次登入（包括使用沒有帳號的電子郵件所做的嘗試），以及結果、瀏覽器和作業系統、位址和所在位置。按一下某個人（或在管理使用者中使用 **登入紀錄與裝置**），即可查看他的登入紀錄和已登入的裝置；**登出** 會結束單一裝置的工作階段，**在所有裝置上登出** 則會結束所有工作階段。其他人只能在 **設定 → 帳號** 中看到自己的紀錄。

ColTex 會自行保護登入，不依賴外部服務。如果某個帳號在最近 90 天內曾從某個位址登入，該位址對這個帳號來說就是熟悉的位址。

- 來自不熟悉位址的失敗次數會計入帳號，不論是哪個位址：從第三次嘗試起，瀏覽器會先自動解一道小謎題（工作量證明，約一秒）；失敗 5 次後須等待 15 分鐘；失敗 10 次後，帳號會對不熟悉的位址 **鎖定**。系統管理員會收到通知，可以在這裡或在管理使用者中解鎖（**解鎖**）。
- 來自熟悉位址時，每失敗 5 次須等待 15 分鐘，但永遠不會被鎖定：帳號被鎖定期間，擁有者仍可以從平常工作的地方登入。
- 網際網路上的某個位址在一小時內失敗 20 次（不論使用哪些帳號），就會被封鎖一天；被封鎖的位址會列在 **登入紀錄** 頂端，並附有 **解除封鎖**。區域網路或 tailnet 上的位址永遠不會被封鎖：可能有多人共用同一個位址。

自己被鎖在外面了？請在伺服器上執行 `coltex unlock <email>`（被封鎖的位址則執行 `coltex unlock <address>`）。

## AI 服務

- **AI 服務**：以 API 金鑰或訂閱帳號登入（Claude Pro/Max、ChatGPT、Copilot…）連接供應商，或連接你自己的 OpenAI 相容伺服器（Ollama、vLLM、LM Studio…）。金鑰會加密儲存，成員永遠看不到，請求都經由這台伺服器發出。
- 如果訂閱帳號登入最後跳轉到一個無法開啟的 localhost 網址，請從網址列複製完整網址，貼回 ColTex。
- 設定好 **自動** 的三個模型後，所有人一開始都會使用自動選擇：**判斷** 模型（便宜、快速的模型）會閱讀每則訊息，再交給 **輕量** 模型（簡單問題、小修正）或 **強力** 模型（多個錯誤、跨檔案修改、需要仔細斟酌的寫作）。三個模型都設定好之前，大家會從自己可以使用的第一個模型開始。
- **網路搜尋**：Anthropic、OpenAI 和 ChatGPT 的模型使用內建的網路搜尋，不需另外設定。其他模型要先 **連接** 一個搜尋服務（DeepSeek、Tavily、Exa 或 Brave Search）並貼上它的 API 金鑰；DeepSeek 也可以直接使用已連接的 DeepSeek 供應商的金鑰。其選單中的 **測試** 會執行一次搜尋。有些帳號要先在供應商那邊允許內建搜尋：若請求出錯，就在該供應商的選單中關閉，它的模型便改用搜尋服務。能使用 AI 代理的人都能使用網路；能使用網路時，AI 代理的修改一律等人審閱。
- **多個搜尋服務**：可以連接多個，正在使用的那個標著 **使用中**；在另一個服務的選單裡選 **用於搜尋** 就改用它。移除正在使用的服務時，會改用下一個已連接的服務。
- **AI 用量與權限**：整體與每個人的請求數和 Token 數。誰可以使用哪些模型，由 **AI 群組** 設定：每個群組可以允許整個供應商（包括日後新增的模型）或個別模型，例如「博士生」使用強力模型，「大學部學生」使用輕量模型。每個人最多屬於一個群組，可以在邀請時選擇，之後也可以在清單中開啟該使用者來變更。不屬於任何群組的人無法使用 AI 代理，因此新使用者在系統管理員將他們加入群組之前都無法使用 AI（由管理員邀請的成員會取得該管理員的群組）。系統管理員一律可以使用所有模型。刪除群組後，其中的成員在加入其他群組之前都無法使用 AI。

  群組也可以限制每位成員每天、每週或每月的用量：Token 數、費用（依牌價），或兩者皆限。成員達到上限後，訊息會被拒絕，直到下一個週期開始（依伺服器時區的日曆日、從星期一開始的週、月）；跨過上限的那則訊息仍會完成。成員可以在 AI 代理的訊息輸入框下方看到自己的用量。系統管理員沒有用量上限。

  要個別調整某個人，請在清單中開啟他：在 **自訂** 下，**個別設定可用模型** 和 **個別設定用量上限** 開啟時會取代其群組的設定（個別設定的存取權限在沒有群組時也有效）。清單中會將他們標示為 **已自訂**。

## 儲存空間與備份

- 專案檔案儲存在本機磁碟或 S3 相容儲存空間中，在伺服器啟動時設定（`STORAGE` 和 `S3_*`）。版本記錄、編譯輸出和編譯器的工作副本則保留在資料目錄中。
- **WebDAV 備份** 會存到 Nextcloud、ownCloud、NAS 或任何 WebDAV 伺服器上的資料夾。每份備份都是一個檔案，包含資料庫、所有專案的檔案及其版本記錄。可以排程每天或每週備份，並選擇要保留幾份。如果伺服器提供應用程式密碼，請使用應用程式密碼。
> **加密**：加密備份（AES-256）還會包含執行個體密鑰，因此還原後已連接的 AI 服務和兩步驟驗證可以繼續使用。**請將密碼另外妥善保存：沒有它就無法開啟備份。** 如果在新伺服器上從未加密的備份還原（執行個體密鑰不同），開啟了兩步驟驗證的人將無法登入，直到你為他們執行 `coltex reset-2fa <email>`。
- 還原需要在伺服器停止時，於伺服器上執行 `restore` 指令；請見維運指南。

## 監控

**總覽** 會顯示伺服器、編譯器和資料庫的即時狀態，並附有 CPU、記憶體和編譯的歷史圖表。伺服器每 10 秒取樣一次並保留 30 天，即使沒有人開啟這個頁面也會持續記錄。

## 網路

**網路** 會列出 ColTex 的連線位址（邀請和 Git 位址都會用到），可以開啟內建的 Tailscale 和 Cloudflare Tunnel，並顯示請求如何到達伺服器。請見 [部署與網路](#/help/deployment)。
