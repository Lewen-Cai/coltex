# 版本記錄

編輯器頂端的 **版本記錄** 會開啟版本記錄檢視。它的運作方式和 git log 類似：每個版本都有一個簡短的 ID（如 `a1b2c3d`）、說明、建立時間和建立者。

- 編輯暫停一段時間後會自動記錄版本，並記下是誰做的修改。
- **儲存版本** 會立即記錄目前的狀態，並附上你寫的說明（類似 commit message）。如果自上個版本以來沒有任何變更，這段說明會成為該版本的標籤。
- 選取一個版本，即可查看它修改了哪些檔案、怎麼修改的，或與目前的專案比較。
- **撤銷這些變更** 只會撤銷該版本所做的變更，之後的修改都會保留（類似 `git revert`）。如果某個檔案之後又被修改且產生衝突，則不會做任何變更，並指出是哪個檔案。
- **還原專案** 會把所有檔案還原成該版本時的狀態；之後新增的檔案會被移除。**還原此檔案** 則只對單一檔案這麼做。
- 撤銷和還原本身也是版本（「撤銷了 a1b2c3d」、「還原到 a1b2c3d」；按一下 ID 即可前往該版本），因此同樣可以復原。
- **新增標籤** 可以為版本命名（例如「已投稿」），方便日後尋找。
- 任何版本的檔案都可以下載為 .zip。

> 在套用 AI 修改、整個專案範圍的取代、git push、撤銷和還原之前，也會先儲存一個版本。
