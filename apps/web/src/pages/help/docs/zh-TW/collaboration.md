# 協作與審閱

## 邀請他人

按一下編輯器右上角的 **共用**：

- 專案只能與在這台伺服器上有帳號的人共用。輸入部分姓名或電子郵件，從清單中選擇帳號，選擇角色後按一下 **+**。
- 沒有帳號的人需要先向管理員或系統管理員取得邀請連結；請見 [管理](#/help/admin)。
- 在成員清單中可以變更角色、轉移擁有權或移除成員。只有擁有者可以管理成員。

### 角色

| 角色 | 可以 |
| --- | --- |
| 擁有者 | 所有操作，包括管理成員、刪除專案和將其發佈為範本 |
| 編輯者 | 編輯和管理檔案，接受或拒絕修改建議 |
| 審閱者 | 只能以追蹤修訂的建議修改文字；加入註解 |
| 檢視者 | 閱讀、編譯、下載、加入註解 |

## 共同編輯

多人可以同時編輯同一個檔案；每個人的游標都有自己的顏色，頂端會顯示目前在線的人。變更會即時同步，不需要儲存。

## 註解

選取文字後，按一下工具列中的註解按鈕（或按 `Mod+Alt+M`）。註解會顯示在左側的 **審閱** 面板中，你可以在那裡回覆、編輯和解決註解。輸入 `@` 可以提及他人，對方會收到通知。

## 追蹤修訂

在審閱面板中，可以為所有人或部分人開啟追蹤修訂。之後的編輯都會成為修改建議：

- 刪除的文字會加上刪除線，新增的文字會醒目標示；
- 編輯者可以逐一或一次全部 **接受** 或 **拒絕**；誤做的決定可以在隨後出現的訊息中按 **復原** 收回（15 分鐘內有效）；
- 審閱者的編輯一律會被追蹤；他們可以在面板中 **撤回** 自己的建議；
- 自己的失誤：`Ctrl/Cmd+Z` 可以復原你被追蹤的編輯，在原處重新輸入你刪除的文字，會直接還原，而不會新增一個建議；
- PDF 顯示的是包含這些建議的文字。

## 聊天

左側欄的 **聊天** 是專案的聊天室：

- `Enter` 送出，`Shift+Enter` 換行。
- `@` 可以提及成員。
- `$…$` 中的數學式會排版顯示，例如 `$x^2$`。

## 通知

在聊天或註解中被提及、有人回覆你的註解，以及被加入專案，都會顯示在 **通知** 中，側邊欄會顯示未讀數量。通知只在 ColTex 中顯示，不會寄送電子郵件。
