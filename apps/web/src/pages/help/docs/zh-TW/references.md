# 參考文獻

左側欄的 **參考文獻** 用來處理專案中的 `.bib` 檔案。

## 引用

**引用** 會列出專案中所有的 `.bib` 條目；可以依作者、標題、年份或鍵搜尋。按一下條目，就會在游標處插入 `\cite{key}`。在編輯器中輸入 `\cite{` 時也會建議可用的鍵。

## 搜尋與新增

在 **新增** 分頁中輸入標題、作者或關鍵字後按 Enter 或 **搜尋**：ColTex 會搜尋 Crossref（期刊、會議論文集、書籍）和 arXiv（預印本），並列出結果，每個來源最符合的排在前面。**+** 會把論文新增到欄位下方所選的 `.bib` 檔案。如果 arXiv 知道某篇預印本的正式發表版本，則會以該版本的 DOI 新增。

DOI（例如 `10.1145/3290605.3300857`）、doi.org 連結或 arXiv 編號會直接新增，不經過搜尋（此時按鈕會顯示 **新增**）。

條目從 doi.org 取得，以不重複的鍵新增到檔案結尾；檔案中已有的條目（相同 DOI）不會重複新增。請檢查取得的內容。

## Zotero

1. 在 **設定 → 同步服務** 中輸入 Zotero API 金鑰（在 zotero.org 的設定中建立；讀取權限就夠了）。它會加密儲存在這台伺服器上，只用來讀取你的文獻庫。
2. 在參考文獻面板的 **Zotero** 分頁中，選擇要匯入成專案中 `.bib` 檔案的文獻庫或分類。
3. **重新整理** 會用 Zotero 中目前的內容取代該檔案，因此請在 Zotero 中修改條目，而不是直接修改檔案。

重新整理時使用的是當初匯入該檔案者的 Zotero 連線。
