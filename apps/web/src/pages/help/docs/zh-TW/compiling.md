# 編譯與 PDF

## 編譯器與主文件

專案設定中有 **編譯器** 和 **主文件**：

- **自動**（新專案的預設值）：每次編譯時依文件內容選擇。導言區（包括它 `\input` 的檔案，以及專案自己的 `.sty`/`.cls`）載入了 `ctex`、`xeCJK`、`fontspec`、`unicode-math` 等套件，或文件類別是 `ctexart`/`ctexbook` 等時使用 XeLaTeX；載入 `luacode` 或 `luatexja` 時使用 LuaLaTeX；其他情況使用 pdfLaTeX。如果第一行是 `% !TEX program = xelatex`，或專案中有 `latexmkrc`，則以它們為準。
- **pdfLaTeX**：英文文件的常用選擇。
- **XeLaTeX**：中文（ctex）和系統字型需要用它。
- **LuaLaTeX**：同樣支援系統字型。

選定某個引擎後，每次都會使用它，不再自動偵測。

> 撰寫中文時，請載入 `\usepackage[UTF8]{ctex}`（或使用 `ctexart` 文件類別），自動模式就會切換到 XeLaTeX。沒有 ctex 的中文文字在 pdfLaTeX 下會失敗，並出現「Unicode character … not set up for use with LaTeX」。

主文件是編譯的起點檔案；請在專案設定的 **主文件** 中選擇。

編譯使用完整的 TeX Live 和 latexmk，它會視需要多次執行 LaTeX、BibTeX/Biber 和索引。編譯在隔離環境中執行，無法連上網路，shell escape 也受到限制。

## 編譯選項

**重新編譯** 旁的箭頭中有：

- **自動編譯**：停止輸入時就會編譯（每個專案一次只會有一個編譯，不論有多少人在輸入）。
- **編譯模式**：一般或快速［草稿］。草稿模式會略過圖片，速度較快。
- **編譯出錯時**：遇到第一個錯誤就停止，或盡量忽略錯誤繼續編譯。
- **清除快取並重新編譯**：編譯結果看起來不對時，刪除輔助檔案並從頭編譯。

這些選項依專案保存在這個瀏覽器中。

## 記錄檔

**記錄檔** 上的數字是錯誤數量。記錄檔會列出錯誤、警告和排版問題：

- 每一項都附有 LaTeX 訊息，常見問題還會附上說明（例如缺少套件時，會指出要加入哪個套件）；
- 按一下即可跳到對應的檔案和行；
- 也可以查看原始記錄檔，AI 還能解釋或修正這些錯誤。

> 編譯失敗時，畫面上會保留上次成功編譯的 PDF。

## 在原始碼與 PDF 之間

- **原始碼 → PDF**：游標停在原始碼中時，按一下 PDF 列上的 **定位**（或右鍵選單中的「跳至 PDF」）；PDF 會捲動到該處並醒目標示。
- **PDF → 原始碼**：在 PDF 上按兩下；編輯器會開啟該檔案並跳到對應的行。

## 版面配置：編輯器、PDF 或兩者

檢視切換（PDF 列右側的四個小按鈕）可以和 Overleaf 一樣顯示 **僅編輯器**、並排的 **編輯器和 PDF** 或 **僅 PDF**，第四個按鈕則會在新視窗中開啟 PDF；這個瀏覽器會記住你的選擇。把分隔線一路拖到某一側，也會隱藏該窗格。

- 只顯示編輯器時，**重新編譯** 和同一組切換按鈕會出現在編輯器工具列的尾端。
- 從編輯器使用 **跳至 PDF**，會在 PDF 隱藏時把它顯示出來。
- 在窄視窗（平板或手機）中一次只能顯示一個窗格，側邊面板（檔案、搜尋…）開啟時會蓋住編輯器。

## 獨立視窗中的 PDF

**在新視窗中開啟 PDF**（檢視切換的最後一個按鈕）會在另一個視窗中開啟 PDF，你可以把它移到另一個螢幕上：

- 編輯器視窗會移除 PDF 窗格，由編輯器佔滿；**重新編譯** 會移到編輯器工具列的尾端。
- PDF 視窗中有重新編譯、記錄檔、跳至 PDF 和下載。在其中的 PDF 上按兩下，會跳到編輯器視窗中的原始碼。
- 按一下編輯器工具列中的 **在此處顯示 PDF**，或關閉該視窗，PDF 窗格就會回來。

## 下載

- PDF 列可以下載目前的 PDF。
- 檔案樹頂端的下載按鈕會把專案的原始檔下載為 .zip。
- 在專案清單中，專案選單（⋯）有 **下載 PDF**（會先編譯）和 **下載 .zip**（包含所有原始檔）。
