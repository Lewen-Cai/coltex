# 快速入門

ColTex 是執行在你自己伺服器上的協作式 LaTeX 編輯器。用起來和 Overleaf 很像：左邊是原始碼，右邊是 PDF，多人可以同時編輯同一個專案。

## 新增專案

按一下左上角的 **新增專案**，輸入名稱並選擇範本：

| 範本 | 文件類別 |
| --- | --- |
| 空白文章 | 標準 `article`，最簡單的起點 |
| arXiv 預印本 | `article`，單欄，作者與所屬機構（authblk），natbib 參考文獻 |
| IEEE 會議 / IEEE 期刊 | `IEEEtran` 的會議 / 期刊模式 |
| ACM 會議 / ACM 期刊 | `acmart` sigconf / acmsmall |
| Springer LNCS | `llncs`，適用於 LNCS 及其他 Springer 會議論文集 |
| Elsevier 期刊 | `elsarticle`，單欄預印本 |
| APS (REVTeX 4.2) | `revtex4-2`，適用於 Physical Review 和 AIP 期刊 |

除了空白文章，每個範本都附有摘要、關鍵字、一個公式、一張圖、一個表格和一份 `references.bib`，不做任何修改就能編譯。這些文件類別都是 TeX Live 內附的官方版本。每年都會發佈新樣式檔的會議（NeurIPS、ICML）不在 TeX Live 中：請把當年的檔案上傳到一個專案，再將它發佈為範本。

其他人發佈為範本的專案（例如實驗室的學位論文格式）會列在「本站共用的範本」之下。

新專案的編譯器是 **自動**：每次編譯時依文件內容選擇引擎；請見 [編譯與 PDF](#/help/compiling)。

要從 Overleaf 搬移專案，請在 Overleaf 選擇 **Download Source** 下載 zip，再在這裡用 **匯入** 上傳（最大 200 MB）。主文件會自動偵測，編譯器同樣是自動。其他編輯器留下的編譯檔案（`.aux`、`.log`、`.synctex.gz` 等）和 `.vscode` 這類資料夾會被略過，和 Overleaf 一樣；`latexmkrc` 和 `.bbl` 檔案會保留。

## 編輯器

- **頂端**：專案名稱、目前在線的人、**版本記錄** 和 **共用**。
- **左側欄**：在檔案、搜尋、參考文獻、審閱、聊天和 AI 之間切換左側面板；鍵盤快速鍵和專案設定在它的底部。
- **中間**：編輯器，工具列中有 **程式碼 / 視覺化** 切換。
- **右側**：PDF，附有 **重新編譯**、**記錄檔**、跳至 PDF 按鈕、在新視窗中開啟和下載。

## 編譯與 PDF

- 按一下 **重新編譯**，或按 `Mod+S` / `Mod+Enter`。自動編譯預設為開啟，停止輸入時就會編譯。
- **記錄檔** 會顯示錯誤數量；開啟後可以看到每個錯誤及其說明，按一下即可跳到對應的行。編輯器的行號旁也會標示錯誤。
- **原始碼 ↔ PDF**：游標停在原始碼中時，按一下 PDF 列上的十字準星，PDF 就會捲動到對應位置；在 PDF 上按兩下則會跳回原始碼。
- **獨立視窗中的 PDF**：PDF 列上的「在新視窗中開啟 PDF」可以把 PDF 放到另一個螢幕上，讓編輯器佔滿自己的視窗。請見 [編譯與 PDF](#/help/compiling)。
