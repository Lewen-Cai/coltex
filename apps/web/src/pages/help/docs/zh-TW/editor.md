# 編輯器

## 程式碼模式與視覺化模式

工具列中的 **程式碼 / 視覺化** 用來切換編輯方式；兩者編輯的都是同一份 LaTeX 原始碼。

- **程式碼**：原始碼本身，具有語法醒目標示、自動完成和括號配對。游標在數學式中時，上方會顯示排版後的公式（按 `Esc` 隱藏）。
- **視覺化**：標題、粗體、清單、數學式、表格和圖片都會以排版後的樣子顯示；游標所在之處則顯示原始碼。適合閱讀和編輯文字。

## 工具列

標題層級、粗體、斜體、數學式、符號、連結、`\ref`、`\cite`、圖片、表格、清單和搜尋。放不下的按鈕會收進 **⋯** 選單。

- **符號**（Σ）：依類別列出希臘字母、運算子、箭頭等；按一下即可插入。
- **表格**：插入時選擇大小。在視覺化模式中，按一下表格即可編輯儲存格（`Tab` 可在儲存格之間移動）；它的工具列可以新增和刪除列與欄、合併儲存格，以及設定對齊和框線。
- **圖片**：上傳圖片、從專案中選擇，或直接把圖片貼上或拖放到編輯器中。在視覺化模式中，圖片上的編輯按鈕可以修改寬度、圖說和標籤。

## 自動完成

輸入 `\` 會建議指令；`\ref{` 和 `\cite{` 會列出專案中的標籤和參考文獻鍵。隨時按 `Ctrl+Space` 都可以開啟建議。

## 錯誤

- **編譯錯誤**：上次編譯在目前檔案中的錯誤和警告，會在行號旁顯示圓點，錯誤還會加上底線。滑鼠移過去可以看到 LaTeX 訊息和說明。
- **語法檢查**：在輸入時檢查，不需要編譯：未關閉或不配對的環境、多餘的 `}` 或 `$`、在數學模式外使用數學指令。正在輸入的地方不會被標示。在某段內容前後加上 `%%begin novalidate` 和 `%%end novalidate` 即可略過檢查。

## 拼字檢查

拼錯的單字會加上紅色虛線底線（不檢查中日韓文字）。在單字上按右鍵可以查看建議或 **加入字典**。檢查語言是專案設定。

你的字典位於編輯器左側欄底部的 **設定 → 字典** 中；其中的單字在你所有的專案中都會被視為正確。在欄位中輸入即可尋找單字，若還沒有這個單字，按 Enter 即可新增；清單上方的字母可以跳到該字母。**⋯** 選單可以匯入文字檔（每行一個單字，或以空格或逗號分隔；Hunspell 的 `.dic` 檔也可以）、把你的單字匯出為 `dictionary.txt`，以及全部移除。已開啟的編輯器會立即重新檢查單字。

## 右鍵選單

剪下、複製、貼上、全選、刪除、跳至 PDF，以及新增註解。在 `\ref{…}` 上會提供 **跳至標籤**；在 `\input{…}` 或 `\include{…}` 上則提供 **開啟檔案**。

## 大綱與路徑導覽

- 檔案樹下方的 **檔案大綱** 會列出目前檔案的章節；按一下即可前往。游標所在的章節會醒目標示。
- 編輯器上方的那一列會顯示游標位置的「檔案 › 節 › 小節」；按一下某個章節即可前往。可以在編輯器設定中關閉。

## 搜尋

`Mod+F`（或 `Mod+Shift+F`，或工具列的搜尋按鈕）會在左側開啟 **搜尋** 面板，並填入選取的文字。它會搜尋整個專案，目前檔案中的結果排在前面，支援規則運算式、區分大小寫和全字比對，可以取代單一結果或全部取代。全部取代之前會先儲存一個版本。

## 編輯器設定

左側欄底部的 **設定** 把設定分成左側的幾個類別：

- **專案**：編譯器、主文件、拼字檢查語言（由編輯者變更，對所有人生效），以及 Git clone 位址；
- **外觀**：字型大小、字型（等寬或無襯線）、行高、**程式碼配色**（GitHub、Solarized、Monokai、Dracula、Nord、One Dark 等，僅限程式碼模式）、路徑導覽；
- **編輯**：按鍵配置（預設、Vim 或 Emacs），以及語法檢查、公式預覽、自動閉合括號和自動完成的開關；
- **鍵盤快速鍵**：見下文；
- **操作**：字數統計、建立副本、匯出為 Word、範本轉換、發佈為範本。

外觀、編輯和快速鍵是你個人的設定，保存在這個瀏覽器中，適用於每個專案。

## 鍵盤快速鍵

左側欄的 **快速鍵** 會列出所有快速鍵。最常用的有：

| 操作 | 按鍵 |
| --- | --- |
| 編譯 | `Mod+S` 或 `Mod+Enter` |
| 復原 / 重做 | `Mod+Z` / `Mod+Shift+Z` |
| 搜尋和取代 | `Mod+F` |
| 粗體 / 斜體 | `Mod+B` / `Mod+I` |
| 註解或取消註解 | `Mod+/` |
| 跳至行 | `Mod+Alt+G` |
| 為選取的文字加入註解 | `Mod+Alt+M` |
| 顯示建議 | `Ctrl+Space` |

按鍵會依你的系統顯示：Mac 上是 ⌘、⌥ 和 ⇧，Windows 和 Linux 上是 Ctrl、Alt 和 Shift。以上是預設按鍵。

### 自訂快速鍵

在設定的 **鍵盤快速鍵** 中，按一下指令旁的 **變更**，然後按下新的按鍵。新按鍵必須包含 Ctrl（Mac 上為 ⌘）或 Alt；已被其他指令使用的按鍵，或保留給瀏覽器和基本編輯操作（復原、複製、貼上、全選…）的按鍵，都無法使用。可以還原單一快速鍵或全部還原。之後工具列提示和快速鍵清單都會顯示你的按鍵。
