# 設定

按一下左下角的頭像，選擇 **設定**。

- **帳號**：你的顯示名稱（協作者、註解和版本記錄中看到的名稱）和密碼。變更密碼時可以同時登出你的其他裝置。密碼至少需要 8 個字元，且須包含大寫字母、小寫字母和數字；符號可有可無。輸入時顯示的強度（弱、普通、良好、強）會隨長度和符號增加而提高。註冊和管理員重設密碼也遵循相同規則。登入用的電子郵件只能由管理員變更。
- **外觀**：主題（藍色的淺色和深色、綠色的森林和苔蘚、紫色的薰衣草和梅子，預設為淺色），以及介面語言（14 種語言，包括 English、简体中文、繁體中文、日本語、한국어、Español、Français 和 Deutsch；預設為瀏覽器的語言）。深色主題也會套用到編輯器；PDF 頁面維持白色。主題會隨你的帳號保存，因此在其他瀏覽器中也會套用（登入頁面一律使用淺色）；語言則保存在這個瀏覽器中。
- **同步服務**：連接你的 Zotero 帳號（請見 [參考文獻](#/help/references)），以及建立和撤銷 git 權杖（請見 [檔案](#/help/files)）：每個權杖可用於 Git、MCP 或兩者，可設為讀寫或唯讀，可用於所有專案或部分專案，並可設定到期日。建議每台電腦使用一個權杖，這樣就能個別撤銷。
- **AI 代理**：你最近 7、30 或 90 天的 AI 用量（請求數、Token 數、費用，依天和依模型），以及剩餘的額度（當你可以使用 AI 代理時）、AI 代理可以替你修改哪些內容（**權限**），以及透過 **MCP** 連接你自己的 AI 代理和它們的權杖；請見 [AI 代理](#/help/ai)。
- **AI Skill**（當你可以使用 AI 代理時）：你自己的 Skill、內建 Skill，以及與 AI 代理一起撰寫 Skill 的對話；請見 [AI 代理](#/help/ai)。

編輯器設定（字型大小、配色、Vim…）位於編輯器左側欄底部的 **設定** 中；請見 [編輯器](#/help/editor)。
