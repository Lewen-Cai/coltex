# 設定

按一下左下角的頭像，選擇 **設定**。

- **帳號**：你的顯示名稱（協作者、註解和版本記錄中看到的名稱）、頭像的顏色（也是你在編輯器中的游標顏色；**自動** 是 ColTex 為你選的顏色），以及你的密碼。變更密碼時可以同時登出你的其他裝置。密碼至少需要 8 個字元，且須包含大寫字母、小寫字母和數字；符號可有可無。輸入時顯示的強度（弱、普通、良好、強）會隨長度和符號增加而提高。註冊和管理員重設密碼也遵循相同規則。登入用的電子郵件只能由管理員變更。兩步驟驗證和你的登入紀錄也在這個頁面上（見下文）。
- **外觀**：主題（藍色的淺色和深色、綠色的森林和苔蘚、紫色的薰衣草和梅子，預設為淺色），以及介面語言（14 種語言，包括 English、简体中文、繁體中文、日本語、한국어、Español、Français 和 Deutsch；預設為瀏覽器的語言）。深色主題也會套用到編輯器；PDF 頁面維持白色。主題會隨你的帳號保存，因此在其他瀏覽器中也會套用（登入頁面一律使用淺色）；語言則保存在這個瀏覽器中。
- **同步服務**：連接你的 Zotero 帳號（請見 [參考文獻](#/help/references)），以及建立和撤銷 git 權杖（請見 [檔案](#/help/files)）：每個權杖可用於 Git、MCP 或兩者，可設為讀寫或唯讀，可用於所有專案或部分專案，並可設定到期日。建議每台電腦使用一個權杖，這樣就能個別撤銷。
- **AI 代理**：你最近 7、30 或 90 天的 AI 用量（請求數、Token 數、費用，依天和依模型），以及剩餘的額度（當你可以使用 AI 代理時）、AI 代理可以替你修改哪些內容（**權限**），以及透過 **MCP** 連接你自己的 AI 代理和它們的權杖；請見 [AI 代理](#/help/ai)。
- **AI Skill**（當你可以使用 AI 代理時）：你自己的 Skill、內建 Skill，以及與 AI 代理一起撰寫 Skill 的對話；請見 [AI 代理](#/help/ai)。

## 兩步驟驗證

開啟兩步驟驗證後，登入時在輸入密碼之後，還需要輸入手機上驗證器應用程式（Google Authenticator、Microsoft Authenticator、1Password、Bitwarden…）產生的驗證碼。是否開啟由你自己決定，其他人無法替你開啟。

1. 在 **設定 → 帳號** 的 **兩步驟驗證** 中，按一下 **開啟** 並輸入你的密碼。
2. 用應用程式掃描 QR 碼（或在其中輸入設定金鑰），然後輸入它顯示的 6 位數驗證碼。
3. 保存 10 組 **復原碼**（複製下來，或下載為檔案）。如果手機遺失，每組復原碼可以代替驗證碼登入一次。復原碼只會在這時顯示。

登入時，輸入密碼後請輸入應用程式中的驗證碼，或按一下 **使用復原碼**。勾選 **這台裝置 30 天內不再詢問** 後，在該瀏覽器中就不必輸入驗證碼。**重新產生復原碼** 會取代舊的復原碼（請保存新的復原碼）；**關閉** 會恢復為只需密碼。Git 和 MCP 權杖的使用方式不變。

> 手機和復原碼都遺失了？系統管理員可以在伺服器上為你的帳號關閉兩步驟驗證（`coltex reset-2fa <email>`）；之後你就能用密碼登入，並可以重新開啟。

## 登入紀錄

**設定 → 帳號** 底部的 **登入紀錄** 會列出你帳號的登入情況，最新的排在最前面：時間、結果（已登入、密碼錯誤、驗證碼錯誤、遭拒絕）、瀏覽器和作業系統，以及位址和所在位置：區域網路、Tailscale，若是網際網路上的位址，則顯示其國家、地區、城市和網路業者。位置資訊來自伺服器上的資料庫；位址從不會傳送到其他地方查詢。紀錄會保留 90 天。

編輯器設定（字型大小、配色、Vim…）位於編輯器左側欄底部的 **設定** 中；請見 [編輯器](#/help/editor)。
