# 设置

点左下角的头像，选 **设置**。

- **账户**：修改显示名称（协作者、评论和历史里显示的名字）和密码。修改密码时可以顺便退出其他设备。密码至少 8 位，必须包含大写字母、小写字母和数字，符号可选；输入时会显示强度（弱、一般、良好、强），更长或带符号的密码更强。注册和管理员重设密码也用同样的规则。登录邮箱只能由管理员修改。
- **外观**：浅色、深色或跟随系统；界面语言（English / 简体中文）。深色模式也作用于编辑器，PDF 页面始终是白色。这些设置保存在当前浏览器里。
- **同步服务**：连接 Zotero 账户（见 [参考文献](#/help/references)），以及创建和撤销 git 令牌（见 [文件](#/help/files)）。建议每台电脑用一个令牌，这样可以单独撤销。
- **AI 技能**（有 AI 智能体时）：你自己的技能、内置技能，以及帮你写技能的 AI 智能体对话框，见 [AI 智能体](#/help/ai)。

编辑器相关的设置（字号、配色、Vim 等）在编辑器左侧竖栏底部的 **设置** 里，见 [编辑器](#/help/editor)。
