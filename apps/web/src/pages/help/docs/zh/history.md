# 历史版本

点编辑器顶部的 **历史版本** 打开历史视图。它和 git log 类似：每个版本都有一个短编号（比如 `a1b2c3d`）、说明、时间和作者。

- ColTex 会自动记录版本：停止编辑一会儿后保存一个版本，并记下是谁改的。
- **保存版本**：马上记录当前状态，并写上你的说明（类似提交信息）。如果和上一个版本相比没有变化，说明会作为标签加到上一个版本上。
- 选中一个版本，可以看到它改了哪些文件、每个文件改了什么。也可以切换成和当前项目对比。
- **撤销这些改动**：只撤销这个版本做的改动，之后的修改都保留（类似 `git revert`）。如果某个文件之后又被改过、和撤销冲突，就什么都不改，并告诉你是哪个文件。
- **恢复项目**：把所有文件恢复成这个版本时的样子，之后新增的文件会被移除。**恢复此文件**只恢复一个文件。
- 撤销和恢复本身也会成为新版本（“撤销了 a1b2c3d”“恢复到 a1b2c3d”，点编号可以跳到对应版本），所以都可以再撤回。
- **添加标签**：给某个版本起个名字（比如“已投稿”），以后方便找到。
- 可以把任意版本的源文件下载成 .zip。

> AI 修改、批量替换、git 推送、撤销、恢复之前，都会先自动保存一个版本。
