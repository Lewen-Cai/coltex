# AI 智能体

左侧竖栏的 **AI** 打开 AI 智能体。管理员接入模型服务、并把你加入某个 AI 用户组后才能使用；你能用哪些模型由所在的用户组决定。

## 能做什么

- 回答 LaTeX 问题，解释选中的代码。
- 解释或修复编译错误（日志面板里也有“用 AI 修复”的入口）。
- 改写、润色、翻译选中的文字。
- 概览整个项目、检查未被引用的标签等。

发消息时，当前文件、选中的文字和最近的编译错误会作为上下文附上，点附件标签可以取消。

## 修改要经过确认

> AI 不会直接改动你的文件。它的修改先放在一份草稿里：

1. AI 完成后会试编译一次草稿，告诉你是否有新错误。
2. 点 **查看修改**，逐个文件看差异，可以只应用一部分。
3. 点 **应用** 后，修改会写进项目并重新编译；如果编译结果变差，会自动回滚。应用前会保存一个历史版本。
4. 应用后可以 **撤销**，撤销时会保留别人在此期间做的修改。

只读成员和审阅者可以向 AI 提问，但不能应用修改。

## 模型和思考

- 面板底部可以选择模型。选 **自动** 时，ColTex 会根据问题的难度在轻量模型和强模型之间选择。
- 支持思考的模型在同一个选择器里调整思考强度，输入框下方会显示当前强度。

## 对话和上下文

- 对话会按项目为你保存（别人看不到）。**新对话** 开始另一个对话；**历史对话** 列出以前的对话，可以打开、重命名或删除。重新打开的对话会接着之前继续；没有应用的草稿不会保留，所以离开有草稿的对话前会先确认。
- 输入框下方的圆环显示这个对话占用了模型上下文窗口的多少（例如 `12k / 200k`），超过 70% 变黄，超过 90% 变红。
- 在输入框里输入 `/` 可以使用命令：
  - `/compact`：总结到目前为止的对话，之后从总结继续，释放上下文。消息仍然显示在面板里，AI 智能体通过总结记得它们。
  - `/new`：开始新对话。
  - `/chats`：历史对话。

## 技能

技能是一套针对反复要做的任务的说明，比如"把摘要压缩到期刊的字数限制内"或"检查每张图是否都被引用"。技能使用 Agent Skills 格式（一个 `SKILL.md`，包含名字、描述和说明），所以为其他 AI 智能体写的技能在这里也能用。

- **你的技能**在**设置 → AI 技能**里，只有你自己看得到。**项目技能**在项目设置的**AI 技能**里：项目里有 AI 智能体的成员都能用，编辑者可以添加和修改。
- 用**新建技能**创建，或者**导入**：**上传文件**可以选一个 `SKILL.md` 和它的参考文件，或一个包含技能文件夹的 `.zip`；**上传文件夹**可以选一个技能的文件夹，或装着多个技能的文件夹。技能里的脚本会作为文本保留，AI 智能体可以阅读，但技能里的任何东西都不会被运行。
- 使用时在输入框输入 `/` 选择技能，再接着写你的消息（`/polish-abstract 控制在 200 词以内`）。AI 智能体也会读技能的描述，请求符合某个技能时会自己用上它。
- 可以让 AI 智能体把某个做法存成技能（"把刚才修参考文献的做法存成技能"）：它会在对话里起草一个，你可以修改，或直接存到你的技能或项目技能。
- **设置 → AI 技能**左边列出你的技能：点一个可以查看它的说明和参考文件；点**用 AI 创建**打开和 AI 智能体的对话，用来写新技能、改进已有的技能（技能上的**在对话中改进**会帮你起好这条消息的开头）。对话按照内置的 **skill-creator** 技能来做：先问你会怎么用这个技能，再起草（需要时带上参考文件），还可以拿你贴进来的文字试用草稿。草稿只有在你保存后才会存下；用已有的名字保存时，会先问你是否替换。对话会一直保留，直到你开始新对话。
- ColTex 自带一些内置技能（列在**内置**下），比如 **skill-creator**。内置技能可以查看和下载，不能修改；你自己建一个同名技能，就会用你的。
- 你的技能和项目技能同名时，用你自己的。

## 你自己的 AI 智能体（MCP）

Claude Code、Codex、Cursor、VS Code 等 AI 智能体可以直接处理项目：读取和搜索文件、修改、编译并查看日志、查看历史版本，以及阅读、添加和回复评论。每个项目都是它们可以连接的 MCP 服务器。

1. 在 **设置 → 同步服务** 里创建令牌（和 Git 用的是同一种令牌）。
2. 在项目设置的 **MCP** 里复制 MCP 地址。
3. 把它加到你的 AI 智能体里，令牌作为 Bearer 令牌。Claude Code：

   ```sh
   claude mcp add --transport http coltex <地址> --header "Authorization: Bearer <令牌>"
   ```

   Codex：写在 `~/.codex/config.toml` 里（令牌放在环境变量 `COLTEX_TOKEN` 里）：

   ```toml
   [mcp_servers.coltex]
   url = "<地址>"
   bearer_token_env_var = "COLTEX_TOKEN"
   ```

   Cursor（`.cursor/mcp.json`）等使用 JSON 配置的工具：

   ```json
   { "mcpServers": { "coltex": { "url": "<地址>", "headers": { "Authorization": "Bearer <令牌>" } } } }
   ```

你的 AI 智能体可以修改什么，由你在每个项目的项目设置 **MCP** 里选择：

- **手动**（默认）：它的修改记为你的修订建议，由你和合作者在 **审阅** 里接受或拒绝。新文件会直接创建。
- **自动**：修改直接生效，和你自己改的一样。如果项目对你开启了修订追踪，仍然记为修订建议。
- **完全访问**：同自动，另外还可以删除、移动和重命名文件。

AI 智能体隔一段时间后第一次修改之前，项目当前的状态会保存为一个历史版本，随时可以回退。审阅者的 AI 智能体只能提出修订建议，查看者的只能阅读和评论。拿到你令牌的人就能以你的身份操作：不再需要时，在 **设置 → 同步服务** 里撤销它。
