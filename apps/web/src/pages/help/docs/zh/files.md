# 文件

## 文件树

- 标题栏上的按钮依次是：新建文件、新建文件夹、上传、添加关联文件。
- 把文件拖到文件夹上可以移动，双击文件名可以重命名。也可以直接把电脑里的文件拖进文件树上传。
- 右键文件或文件夹可以新建、上传、重命名、删除。
- 文件名旁的彩色小圆点表示其他人正在看这个文件。

删除的文件可以在历史版本里找回。

## 关联文件

关联文件是从别处“引用”来的文件，可以随时刷新成来源的最新内容：

- **来自其他项目**：另一个项目里的任意文件，或者它编译出的 PDF（会先编译一次）。适合多个项目共用图片、`.bib`，或者把一个项目的 PDF 作为插图放进另一个项目。
- **来自网址**：从一个公开网址下载文件（最大 50 MB）。出于安全考虑，内网和本机地址不能用。

> 关联文件在文件树里带有链接标记，鼠标悬停可以看到来源。右键选 **刷新关联文件** 会重新获取并覆盖它。添加或刷新时，你自己必须有来源项目的访问权限。
