# 编辑器

## 代码模式和可视化模式

工具栏左侧的 **代码 / 可视化** 用来切换编辑方式，两者编辑的是同一份 LaTeX 源码：

- **代码模式**：直接编辑源码，有语法高亮、自动补全、括号匹配。光标进入公式时，上方会显示渲染后的公式预览（按 `Esc` 隐藏）。
- **可视化模式**：标题、加粗、列表、公式、表格和插图按排版后的样子显示，光标移到某处时才露出那里的源码。适合通读和改文字。

## 工具栏

工具栏可以设置标题级别、加粗、斜体，插入公式、符号、链接、`\ref`、`\cite`、插图、表格和列表，还有搜索替换。放不下的按钮会收进 **⋯** 菜单。

- **符号面板**（Σ）：按类别找希腊字母、运算符、箭头等，点一下插入。
- **表格**：插入时选择行列数。在可视化模式里点表格可以直接编辑单元格，`Tab` 切换单元格，工具栏可以加减行列、合并单元格、设置对齐和边框。
- **插图**：可以上传图片、从项目文件里选，也可以直接把图片粘贴或拖进编辑器。可视化模式里点插图上的编辑按钮，可以改宽度、图注和标签。

## 自动补全

输入 `\` 会提示命令，输入 `\ref{` 或 `\cite{` 时会列出项目里的标签和参考文献条目。`Ctrl+Space` 可以随时手动打开补全。

## 错误提示

- **编译错误**：最近一次编译里属于当前文件的错误和警告，会在行号旁显示红点或黄点，错误处带下划线。鼠标移上去会显示 LaTeX 原文和中文说明。
- **语法检查**：边写边查，不用编译。能发现环境没闭合或不匹配、多余的 `}` 或 `$`、数学命令写在公式外等问题。正在输入的位置会暂时不报。不想检查某一段时，用 `%%begin novalidate` 和 `%%end novalidate` 把它围起来。

## 拼写检查

拼写错误的单词下面会出现红色虚线（中文不检查）。右键点它，可以看到建议，或者 **加入词典**。检查语言在项目设置里改。

个人词典在编辑器左侧栏底部的 **设置 → 词典** 里，里面的单词在你所有项目里都视为正确。在输入框里输入可以查找单词，不在词典里的按回车就能添加；列表上方的字母可以跳到对应位置。**⋯** 菜单里可以导入文本文件（每行一个单词，或用空格、逗号分隔；也支持 Hunspell 的 `.dic` 文件）、把单词导出为 `dictionary.txt`，或者全部移除。改动会立刻在打开的编辑器里生效。

## 右键菜单

在编辑器里右键可以：剪切、复制、粘贴、全选、删除、定位到 PDF、添加评论。光标在 `\ref{…}` 上时可以 **跳转到标签**；在 `\input{…}` 或 `\include{…}` 上时可以 **打开文件**。

## 文件大纲和路径导航

- 文件树下面的 **文件大纲** 列出当前文件的章节，点一下跳过去，当前所在章节会高亮。
- 编辑区上方一行显示“文件 › 节 › 小节”，表示光标所在的位置，点节名也能跳转。不需要的话，可以在编辑器设置里关掉。

## 搜索

按 `Mod+F`（或 `Mod+Shift+F`、工具栏上的搜索按钮）会打开左侧的 **搜索** 面板，选中的文字会自动填进去。它搜索整个项目，当前文件的结果排在最前面；支持正则表达式、区分大小写和全词匹配，可以逐个替换，也可以全部替换。全部替换前会先保存一个历史版本。

## 编辑器设置

点左侧竖栏底部的 **设置**，弹窗左边按类别分组：

- **项目**：编译器、主文档、拼写检查语言（只有编辑者能改，对所有成员生效），以及 Git 克隆地址；
- **外观**：字号、字体（等宽或无衬线）、行距、**代码配色**（GitHub、Solarized、Monokai、Dracula、Nord、One Dark 等，只作用于代码模式）、路径导航；
- **编辑**：键位（默认、Vim 或 Emacs），语法检查、公式预览、自动闭合括号、自动补全的开关；
- **快捷键**：见下文；
- **操作**：字数统计、复制、转换模板、发布为模板。

外观、编辑和快捷键只对你自己生效，保存在当前浏览器里，所有项目通用。

## 快捷键

点左侧竖栏的 **快捷键** 可以看到完整列表。常用的有：

| 操作 | 快捷键 |
| --- | --- |
| 编译 | `Mod+S` 或 `Mod+Enter` |
| 撤销 / 重做 | `Mod+Z` / `Mod+Shift+Z` |
| 搜索和替换 | `Mod+F` |
| 加粗 / 斜体 | `Mod+B` / `Mod+I` |
| 注释或取消注释 | `Mod+/` |
| 跳到指定行 | `Mod+Alt+G` |
| 评论选中的文字 | `Mod+Alt+M` |
| 打开补全 | `Ctrl+Space` |

快捷键按你的系统显示：Mac 上是 ⌘、⌥、⇧，Windows 和 Linux 上是 Ctrl、Alt、Shift。这里列的是默认按键。

### 自定义快捷键

在设置的 **快捷键** 里点某个命令旁边的 **修改**，再按下新的组合键。组合键要带 Ctrl（Mac 上是 ⌘）或 Alt；已经被其他命令使用、或者留给浏览器和基本编辑（撤销、复制、粘贴、全选等）的组合不能用。可以单独恢复某一项，也可以全部恢复默认。改过之后，工具栏提示和快捷键列表都会显示你的按键。
