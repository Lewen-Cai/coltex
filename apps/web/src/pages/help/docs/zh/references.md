# 参考文献

左侧竖栏的 **参考文献** 面板管理项目里的 `.bib` 文件。

## 引用

**引用** 页列出项目里所有 `.bib` 条目，可以按作者、标题、年份或键名搜索。点一个条目，会在光标处插入 `\cite{键名}`。在编辑器里输入 `\cite{` 也会弹出补全。

## 搜索并添加

在 **添加** 页输入标题、作者或关键词后按回车：ColTex 会搜索 Crossref（期刊、会议论文、图书）和 arXiv（预印本），把结果列出来，两边最相关的排在前面。点 **+** 就把这篇文献加到输入框下方选中的 `.bib` 文件里。如果 arXiv 知道某篇预印本的正式发表版本，会按正式版本的 DOI 添加。

输入 DOI（如 `10.1145/3290605.3300857`）、doi.org 链接或 arXiv 编号时，直接添加，不再搜索。

条目从 doi.org 获取，追加到文件末尾，引用键自动生成且不会重复；文件里已有同一个 DOI 的条目时不会重复添加。请核对获取到的内容。

## Zotero

1. 在 **设置 → 同步服务** 里填入 Zotero 的 API 密钥（在 zotero.org 的设置里创建，只需要读取权限）。密钥加密保存在服务器上，只用于读取你的文献库。
2. 在参考文献面板的 **Zotero** 页选择文献库或分类，导入成项目里的一个 `.bib` 文件。
3. 之后点 **刷新** 会用 Zotero 里的最新内容替换这个文件。所以请在 Zotero 里修改条目，不要直接改这个 `.bib`。

刷新时使用的是当初导入的那个人的 Zotero 连接。
