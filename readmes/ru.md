<a id="quick-start"></a>
## Быстрый старт

Нужна машина с Linux или macOS и Docker (в Linux установщик может его поставить), не менее 2 ядер ЦП и 4 ГБ памяти. Образы собраны заранее для x86-64 и ARM64.

```sh
curl -fsSL https://coltexeditor.github.io/install.sh | bash
```

Затем откройте `http://<сервер>:3690` и создайте учётную запись администратора.

<a id="why"></a>
## Почему ColTex?

ColTex — альтернатива Overleaf для научной группы, лаборатории или лично для вас, работающая на компьютере, который вы контролируете: на рабочей станции в лаборатории, домашнем сервере или облачной машине.

- **Всё остаётся на вашем сервере.** Проекты, история, учётные записи и задания компиляции никогда его не покидают. TeX работает в изолированном контейнере без доступа к интернету.
- **Создан для совместного написания.** Несколько человек одновременно редактируют один файл, с комментариями, отслеживанием изменений, чатом и историей версий.
- **ИИ-агент, который работает с вашим проектом.** Он читает файлы и журнал компиляции, готовит изменения, выполняет их пробную сборку и показывает вам различия. Ничего не записывается, пока вы не примените изменения.
- **Установка одной командой, без открытия портов.** Для удалённого доступа встроены Tailscale и Cloudflare Tunnel.

<a id="features"></a>
## Возможности

### Написание и компиляция
- Редактор кода (CodeMirror) и визуальный редактор с редактором таблиц и диалогом рисунков из Overleaf, панелью инструментов, палитрой символов, структурой документа и навигационной цепочкой.
- Автодополнение LaTeX, проверка кода, предпросмотр формул, проверка орфографии на многих языках, подсчёт слов, поиск и замена по всему проекту, а также клавиши Vim или Emacs.
- Компиляция с latexmk на полном TeX Live. Движок (pdfLaTeX, XeLaTeX или LuaLaTeX) выбирается по документу, в том числе для китайского (ctex, xeCJK).
- Предпросмотр PDF с SyncTeX в обе стороны, в том числе в отдельном окне. Ошибки компиляции подчёркиваются в исходном коде и сопровождаются понятными подсказками.
- Библиография: цитирование из ваших файлов `.bib`, поиск в Crossref и arXiv (или вставка DOI либо идентификатора arXiv) для добавления записей, импорт библиотеки или коллекции Zotero с синхронизацией.

### Совместная работа
- Редактирование в реальном времени с курсорами всех участников, комментарии с @упоминаниями, отслеживание изменений (принять, отклонить и отменить решение), чат проекта и уведомления в приложении.
- Роли в проекте: владелец, редактор, рецензент (только предложения) и читатель.
- История версий как в git: автоматические версии, версии с сообщением и отмена изменений одной версии.
- Доступ через Git: клонируйте проект, работайте с ним локально и отправляйте изменения обратно (личные токены; правки, сделанные тем временем в браузере, объединяются).

### ИИ-агент
- Спрашивайте о LaTeX, своём проекте или тексте или поручите ему исправить ошибки компиляции. Он готовит изменения в личной копии, выполняет их пробную сборку и показывает различия; вы применяете их целиком или частично.
- Перед применением сохраняется версия, затем проект перекомпилируется; если сборка ухудшилась, изменение автоматически откатывается.
- Провайдеры: ключи API (Anthropic, OpenAI, DeepSeek, Google, OpenRouter и другие), вход с подпиской (Claude Pro/Max, ChatGPT, GitHub Copilot и другие) или собственный OpenAI-совместимый сервер (Ollama, vLLM, LM Studio).
- Автоматический выбор модели (лёгкая или мощная модель для каждого сообщения), доступ по группам людей, учёт использования по каждому человеку и лимиты использования на день, неделю или месяц.
- Сохранённые чаты для каждого проекта, отображение занятого контекстного окна и `/compact` для краткого изложения длинного чата.
- Skills: ваши собственные инструкции (формат Agent Skills) для всех ваших проектов, которым следует агент, вызываются через `/name`; пишите их сами, импортируйте или создавайте с ИИ в настройках.
- Права как в Claude Code: изменения ИИ-агента ждут вашей проверки (Вручную), применяются, когда он закончит (Авто), или он может также удалять и перемещать файлы (Полный доступ).
- Ваш собственный агент (Claude Code, Codex, Cursor…) через MCP: один адрес для всех ваших проектов, с теми же правами (в режиме «Вручную» его правки становятся вашими предложениями).

### Проекты и администрирование
- Шаблоны для IEEE, ACM, Springer LNCS, Elsevier, REVTeX и arXiv и преобразование статьи из одного шаблона журнала в другой.
- Импорт и экспорт zip из Overleaf, файлы, связанные с URL или другим проектом, теги, архив и корзина.
- Открытой регистрации нет: учётные записи создаются по ссылкам-приглашениям. Один системный администратор и администраторы, каждый из которых управляет приглашённой им командой.
- Мониторинг, резервное копирование в WebDAV (по желанию с шифрованием), локальное или S3-совместимое хранилище, светлая и тёмная темы и интерфейс на 14 языках (английский, китайский, японский, корейский, испанский, французский, немецкий, португальский, итальянский, русский, турецкий, вьетнамский и индонезийский).
- Безопасность учётных записей: двухэтапная проверка через приложение-аутентификатор, журнал входов с местоположением каждого адреса (определяется на сервере) и защита от подбора паролей, которая блокирует учётную запись для незнакомых адресов, — всё без сторонних сервисов.

<a id="install"></a>
## Установка

Если загрузка обрывается (`curl: (35) Recv failure: Connection reset by peer`, такое бывает, когда GitHub плохо доступен), просто запустите команду ещё раз.

Установщик спрашивает язык и редакцию TeX Live (выбор стрелками), загружает последний выпуск в `~/coltex`, скачивает готовые образы с индикатором прогресса, запускает ColTex и выводит адреса, которые нужно открыть. Полный вывод записывается в `~/coltex/install.log`. Затем откройте `http://<server>:3690` и создайте учётную запись администратора. Удалённый доступ через Tailscale или Cloudflare Tunnel включается потом в разделе **Настройки → Сеть**.

При первом запуске скачивается TeX Live. Выберите редакцию:

| Редакция | Загрузка | На диске (весь ColTex) | Нужно свободного места |
| --- | --- | --- | --- |
| **standard** (по умолчанию) | около 3 ГБ | около 12 ГБ | 20 ГБ |
| **full** (`--edition full`) | около 8 ГБ | около 23 ГБ | 35 ГБ |

Обе редакции содержат все пакеты TeX Live и компилируют одни и те же документы, и ИИ-агент работает с любой из них. В редакции standard нет руководств пакетов; редакция full добавляет руководства и исходники, которые ИИ-агент тоже может читать.

`--edition` и `--lang` отвечают на вопросы установщика или заменяют их, если терминала нет. `--domain`, `--tailscale` и параметры Cloudflare сразу настраивают удалённый доступ при установке из скрипта. Параметры добавляются после `bash -s --`:

| Параметр | |
| --- | --- |
| `--domain tex.example.org` | HTTPS для сервера со своим доменом через встроенный Caddy. Направьте домен на сервер и откройте порты 80 и 443 |
| `--tailscale` | Подключить ColTex к вашему tailnet: выводит ссылку для входа и QR-код |
| `--cloudflare-token TOKEN` | Подключить туннель Cloudflare, созданный для вашего собственного домена |
| `--cloudflare-quick` | Временный публичный адрес `trycloudflare.com`, чтобы попробовать |
| `--edition full` | Полная редакция TeX Live |
| `--lang LANG` | Язык установщика, `coltex` и страницы первоначальной настройки: `en`, `zh-CN`, `zh-TW`, `ja`, `ko`, `es`, `fr`, `de`, `pt-BR`, `it`, `ru`, `tr`, `vi` или `id` (если не указан, будет задан вопрос) |
| `--port 3690` | Другой порт |
| `--version v0.0.1` | Конкретный выпуск (`main` — ветка разработки) |
| `--build` | Собрать образы из исходного кода на этой машине вместо скачивания |
| `--images REGISTRY` | Откуда скачивать образы: `aliyun` (те же образы в Alibaba Cloud), `ghcr` (`ghcr.io/coltexeditor`) или другое зеркало ghcr.io. Без этого параметра установщик берёт тот из двух, что отвечает отсюда быстрее (`registry-mirrors` в Docker действует только для Docker Hub, а не для ghcr.io) |

На сервере, доступном из интернета, не входите по открытому `http://`: используйте `--domain`, Tailscale или туннель Cloudflare.

### Управление и обновление

```sh
coltex status          # running? at which address
coltex logs            # the server's log (coltex logs compiler for the compiler)
coltex update          # to the latest release; your settings and data stay
coltex version
coltex edition full    # switch the TeX Live edition
coltex tailscale up    # or: coltex cloudflare quick | token
coltex stop | start
coltex reset           # delete all data and start again from the setup page (asks first)
coltex uninstall       # remove ColTex from this machine: containers, data, images, this folder (asks first)
```

<a id="configure"></a>
## Настройка

Всё настраивается в браузере, в разделе **Настройки** меню пользователя:

1. **Управление пользователями** и **Приглашения**: приглашайте людей по ссылкам (каждая работает один раз, по желанию — только для одного адреса электронной почты).
2. **ИИ-сервисы**: подключите провайдера. Затем в разделе **Использование ИИ и доступ** добавьте людей в группу, которой он разрешён. Без группы ИИ-агент недоступен никому, кроме системного администратора.
3. **Сеть**: адреса, по которым доступен ColTex, а также Tailscale и Cloudflare Tunnel.
4. **Хранилище и резервные копии**: ежедневное или еженедельное резервное копирование в папку WebDAV (Nextcloud, NAS…).

Справка встроена в ColTex: пункт **Справка** в меню пользователя. Эксплуатация сервера (переменные окружения, S3, восстановление из резервной копии) описана в [docs/operations.md](../docs/operations.md) (на английском).

<a id="development"></a>
## Разработка

Node 24 или новее, pnpm 11 и Docker.

```sh
pnpm install
cp .env.example .env
pnpm infra:up        # Postgres, Valkey and the TeX Live compiler in Docker
pnpm dev             # API on :3000, web app on http://localhost:5173
pnpm -r typecheck
pnpm -r test         # the server tests need Postgres from infra:up
```

| Путь | |
| --- | --- |
| `apps/web` | Веб-приложение: React, CodeMirror 6, PDF.js |
| `apps/server` | API: Fastify, учётные записи, проекты, совместная работа в реальном времени, ИИ-агент |
| `services/compiler` | Обработчик компиляции в контейнере TeX Live |
| `packages/*` | Общие схемы, парсер журналов, поддержка языка LaTeX, данные рецензирования и преобразование шаблонов |

Архитектура описана в [docs/architecture.md](../docs/architecture.md) (на английском).
